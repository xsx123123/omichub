## P0 调查修订（后续提示词以本节约束为准）

代码调查已交付：[P0 现状调查、能力矩阵与缺口](CygnusX报告Copilot_P0现状调查.md)。P1 查看页和浏览器绑定预览鉴权已接入，详见 [P1 施工与验证记录](../../implementation/cygnusx-report-viewer-p1.md)；P2 报告绑定会话、只读工具和侧栏已接入，详见 [P2 施工与验证记录](../../implementation/cygnusx-report-copilot-p2.md)。P1/P2 真实报告人工验收待完成，P3 未开始。P2 尚无报告生成期元数据持久化和存量回填；没有核验真实业务库或修改业务容器。下列调查条目记录 P0 时的差距，当前实现以施工记录和活动架构为准。

1. **复用入口**：前端为 Vue 3/TS/Naive UI。报告列表 `frontend/src/views/ReportsView.vue`，路由 `frontend/src/router/index.ts`，外壳 `frontend/src/layouts/DefaultLayout.vue`；后端为 `src/cygnusx/api/v1/reports.py` 与 `application/services/report_service.py`。新增 `/reports/:reportId/view` 挂同一外壳；保留 `?reportId=` 深链接兼容。
2. **报告种类与存储**：`reports` 不只包含科学 HTML，还有执行证据、Studio 衍生版本、交付包；独立项目报告另有 ProjectReportJob。科学报告由 RNA/ATAC 流程生成，通常登记 `Analysis_Report/index.html`，也可由 ARDP manifest 指定入口。不得统一拼接一个假定 results 路径，交付 ZIP 继续下载。
3. **鉴权**：现有预览是 axios Bearer 拉 HTML → `srcdoc`；没有报告签名 URL。S3 预签名下载只能证明持有签名，不能证明浏览器已登录。P1 新短时凭证必须绑定 owner/report/浏览器预览会话并复核权限；单独复制 URL 到没有该会话的浏览器应拒绝，禁止把 access token 放进 URL。签发仍走现有鉴权 API，不把签名链接当公开分享能力。
4. **HTML 交互**：报告中心目前空 sandbox 禁脚本。P1 应采用 opaque-origin iframe + 受限脚本/CSP，不授予 allow-same-origin/顶层导航。新窗口打开受控平台查看路由，不能裸执行 HTML。P2 listener 只注入预览副本，不改归档字节/冻结摘要；postMessage 校验 source、消息格式和当前报告。
5. **项目身份与元数据**：Report/Task 无通用 project_id；只有部分 Dataset 任务存在可核验的项目关联，Studio 报告可能没有真实 Task。基础流程/样本数已落库，完整分组/QC/结果引用摘要尚无。P2 需版本化摘要与迁移/幂等回填，保留来源和缺失状态，不从目录名称或客户端参数猜项目；无项目的历史报告可查看、按报告 scope 降级，但不能跨项目取数或保存。
6. **工具机制**：复用 `infrastructure/mcp/presets.py` / `pipeline_preset.py`、`ToolInvocationContext`、请求级工具裁剪；底层读取可复用 `application/services/pipeline_result_service.py`。P2 仅开放三个报告绑定的只读工具，server-side report/session scope 不出现在模型可控参数中；现有通用 Task/用户文件/写入/执行工具不得借面板绕过该边界。
7. **沙箱差距**：Studio 当前挂载用户整根数据 ro，普通 Chat 池按用户复用且 input 为 rw、CPU 用 shares。P3 需报告专用会话及项目结果 ro 挂载策略、硬 CPU/内存/时长/总输出限额、默认禁网及真实 Docker 验证。现有每次执行启动新 Python/R 进程；容器/文件复用不等于变量保留，后者仍须补常驻解释器协议。恶意读取验收指宿主/其他项目/其他会话数据，运行库和 `/tmp` 等必要路径不属于禁止访问的数据。
8. **保存与计费**：已有 `studio_context_service.py#register_artifact_report` 与 `CookieService.pre_deduct/settle/refund`。但现有 artifact_register 可受 auto_approve/always_allow/权限模式跳过，沙箱执行尚未接预扣实结。P3 必须每次由人类确认具体文件内容，服务端一次性凭证不可被模型自证或自动审批绕过；按执行 ID 做计费幂等/恢复，正式产物保留来源和对话关联。

这些修订补齐原目标的实施前提，不缩减 P1/P2/P3 范围。完整文件/函数定位、验收关闭条件见 P0 调查；原阶段人工验收门禁继续有效。

## 一、背景与目标

原始需求记录平台「结果报告中心」有 137 份报告（数量及现场类型未在 P0 代码调查中核验），包含 GO/KEGG 富集、差异分析火山图、RNA-seq 差异表达等。目标是展示其中的自渲染 HTML 科学报告（BioReport，含项目概述/样本信息/分析概述/质量控制/分析结果/溯源信息/关于等页签）；现有执行证据报告、Studio 版本与交付 ZIP 同时保留各自语义。

目标能力三层：

1. **P1 报告嵌入查看**：在平台内直接打开网页报告（iframe 嵌入 + 平台外壳 + 鉴权），不从浏览器新标签裸开。
2. **P2 AI 解读对话面板**：看报告时右侧可展开 AI 对话栏，AI 绑定当前报告上下文，可通过只读工具查询该项目的结果数据、解读报告章节。
3. **P3 沙箱高级分析**：AI 可调用平台沙箱执行代码，基于报告结果数据做追问式高级分析（重新绘图、统计检验、自定义筛选），产出注册回项目产物列表，接入平台积分计费。

设计参考（原提案背景，非平台现状或本轮运行验收依据）：

- Power BI Copilot 模式：AI 面板绑定当前报告上下文 + 底层语义模型，是报表消费层的标准形态；
- E2B 类 Firecracker microVM 沙箱：原提案的沙箱交互参考；本任务复用平台 Docker，实现与性能以本地代码和运行验证为准，不采用未经本轮验证的冷启动数值；
- Agent 沙箱安全硬共识：隔离由执行环境强制，不靠提示词；最小权限、只读挂载、默认禁出网、资源限额是标配。

## 三、总体架构

```
报告中心列表 ──预览──▶ 报告查看页（平台路由，如 /reports/:reportId/view）
                          ├─ 顶栏/侧栏：CygnusX 平台外壳（不变）
                          ├─ 主体：iframe ──▶ BioReport 静态 HTML（签名 token 鉴权）
                          └─ 右侧抽屉：AI Copilot 面板
                                │  context: reportId → 结构化摘要注入
                                ├─ 只读工具（P2）：query_project / read_report_section / list_artifacts
                                └─ 执行工具（P3）：run_sandbox_code
                                      ├─ 只读挂载：后端核验的当前项目结果根 → 容器内 /data（ro）
                                      ├─ 工作区：会话级 /workspace（rw），产出经人类确认后注册回项目产物
                                      ├─ 限制：禁出网（白名单 PyPI 等）、CPU/内存/wall-clock/输出大小限额
                                      └─ 计费：积分预扣 → 执行 → 实结
```

关键数据前提（已完成代码调查，事实与差距见顶部修订及 P0 交付；现场验证待各阶段执行）：

- 报告 HTML 的生成/存储位置与访问方式（静态目录？对象存储？现有下载接口怎么走？）；
- 报告生成时是否有结构化元数据落库（样本数、分组、Q30、核心指标）——没有则 P2 需补一步「报告元数据落库」；
- 现有沙箱的调用入口（已有任务中心/生信工具箱在用？调用契约是什么）、隔离配置（网络/挂载/限额现状）；
- 平台工具集的 MCP 化现状与命名规范（新工具须遵从既有命名）。

## 四、写死的边界（不做的事）

1. AI **不给跨项目数据权限**——所有工具的作用域参数（projectId）由后端从会话上下文注入，禁止模型自行指定其他项目。
2. 沙箱代码**默认只产出到会话工作区**；写入项目正式产物目录需用户在对话中显式确认（前端确认卡片），不允许 AI 静默落盘。
3. **不做 AI 自动修改报告正文**——报告是可溯源产物，AI 只能「追加附录」（追加也走用户确认）。
4. 报告 HTML 不重渲染、不拆进平台组件库——iframe 嵌入是刻意的交付形态，不是技术债。
5. P2 阶段不接沙箱执行——只读问答先跑通上下文注入与工具调用链路，避免两个阶段的问题搅在一起。

## 七、P2：AI 解读对话面板（只读工具，不接沙箱）

## 八、P3：沙箱高级分析（执行工具）

目标：AI 可在对话中调用平台沙箱执行代码，基于当前项目结果做高级分析；产出注册回项目；
积分预扣实结。

前置确认（P0 第 4 项已给出事实）：若现有沙箱缺以下任一条，先补再开工具——
只读挂载支持、出网限制（默认禁，白名单放行 PyPI/CRAN 等）、CPU/内存/wall-clock 限额、
单会话隔离与销毁。

### P3 提示词（粘给编码 Agent）

```text
你是一名资深后端/平台工程师。在 P2 已完成的 AI 面板中新增沙箱执行工具，使 AI 能对当前
项目结果数据做代码级高级分析。先阅读 P0 调查报告中沙箱调用契约部分
（src/cygnusx/infrastructure/studio/manager.py#StudioSandboxManager.exec、
deploy/studio/sandbox_agent.py#_stream_exec）与 P2 工具注册机制，遵从既有规范。
先完成 P0 列出的项目挂载、每次保存强制确认、执行计费和变量状态差距，再开放工具。

## 权限边界（硬性要求，逐条对应实现与测试）

1. 数据挂载：沙箱启动时仅将「当前项目」的结果目录以只读挂载到容器内 /data；
   projectId 由后端从会话上下文注入，模型不可指定。另挂会话级可写工作区 /workspace。
2. 网络：默认禁出网；如现有沙箱支持白名单，仅放行包管理镜像（PyPI/CRAN），其余拒绝。
3. 限额：CPU/内存/wall-clock（如 2C/4G/10min，可调）与单次输出体积上限；超限即终止
   并返回结构化错误。
4. 确认门：AI 将 /workspace 中的产出「保存到项目产物」时，前端弹确认卡片（文件名/类型/
   大小/预览），用户确认后才执行注册；AI 无权直接写项目正式目录。
5. 计费：执行前按预估时长预扣积分，结束后按实际用量实结多退少补；余额不足时在对话内
   明确提示，不发起执行。复用平台现有积分接口。

## 功能需求

1. 新工具 run_sandbox_code：入参 {language, code, purpose}；返回 {stdout/stderr 摘要,
   生成文件清单（含图表）, 资源用量}；图表以图片形式直接渲染进对话消息。
2. 会话复用：同一对话内沙箱会话持续（变量/中间结果保留），对话结束或超时后销毁；
   复用现有沙箱生命周期管理。现有执行器每次启动新进程，须补常驻解释器协议验证
   跨轮变量；仅复用容器/文件不满足该要求，不允许默默缩减为文件级状态。
3. 产出注册：确认保存的产出登记到项目产物列表（数据管理/报告中心可见），记录来源
   「AI 沙箱分析」与关联对话 ID；这是与既有模块的闭环点，必须有。
4. 典型场景自检（作为 e2e 用例，用合成夹具数据）：
   a. 「用差异分析结果重画一张火山图，标注我指定的基因」→ 返回图片；
   b. 「对富集结果按 p.adjust < 0.01 过滤并统计各 ONTOLOGY 条目数」→ 返回表格；
   c. 恶意/越权用例：代码中尝试访问宿主/其他项目/其他会话数据、尝试出网、尝试写项目目录
      → 均被阻断并返回明确错误（记录错误信息与阻断位置）。
      容器运行库、解释器及 /tmp 等必要路径本身不作为未授权数据；另验证目录穿越/软链。
5. 降级：沙箱服务不可用时工具返回「暂不可用」结构化错误，对话面板其他功能不受影响。

## 验收标准

- [ ] e2e 场景 a/b 通过，图表渲染进对话，数据与产物文件一致
- [ ] 越权用例 c 三项全部阻断，后端日志/审计有记录（不接受仅前端表现为据）

- [ ] 对话内多轮代码执行共享沙箱状态；关闭对话后沙箱销毁（查容器清单为据）
```

## 九、风险与回退

| 风险 | 阶段 | 应对 |
|---|---|---|
| 报告元数据未落库，上下文注入无数据源 | P2 | P0 确认后先补落库 + 存量回填脚本；回填完成前面板降级为通用问答 |
| iframe 与平台鉴权打架（cookie/跨域） | P1 | URL 短时签名与浏览器预览会话双校验；签发走现有登录鉴权，退出登录使预览失效；HTML 响应保持 opaque origin 与 CSP，禁止改成公开预签名下载 |
| postMessage 章节定位对存量报告不生效 | P2 | 查看页代理注入 listener 脚本兜底，新报告模板原生内置 |
| 沙箱隔离配置不达硬要求 | P3 | 不达要求不开工具；临时方案：P3 降级为「生成代码 + 用户手动到生信工具箱运行」 |
| AI 回答编造数据（幻觉） | P2/P3 | 工具返回为唯一数据来源；system prompt 写死「数据类回答必须来自工具返回，不得编造」；验收用产物文件核对 |
| 共享图表/渲染函数改动影响其他页面 | 全程 | 凡改动共享组件，报告中心列表、AI 助手模块、数据管理三处都回归 |
