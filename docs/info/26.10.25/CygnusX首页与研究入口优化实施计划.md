# CygnusX BioOps 首页与研究入口优化实施计划

> 创建：2026-10-25 ｜ 范围：首页 hero 卡片视觉、CTA 入口导流、寻宝鼠作为「科学发现核心」载体的演进评估
> 使用方式：每个任务块的提示词可直接粘贴给编码 Agent；验收权在用户手里，不接受编码 Agent 自报通过。

## 一、背景与评估结论（verdict）

用户提出三条想法，经业界做法求证后结论如下：

### 想法 1：首页欢迎卡片颜色偏深 —— 成立

现状：hero 卡片为深蓝紫深色渐变，页面主体为浅灰白工作台基调，视觉权重失衡，次级文字对比度偏低。
方向：保留品牌渐变作为点缀，卡片主体改浅色，属「优化现有页面」，非重新设计。

### 想法 2：「开始一项研究」入口指向寻宝鼠 —— 成立

业界锚点：Web of Science Research Assistant 采用 One-Box 设计——页面顶部一个输入框（"What are you researching today?"）是整个研究旅程的起点，提问、探索主题、检索文献、创建综述、Deep Search 等都在同一对话中连续流动，无需切换工具。研究从「问题」出发，对话式 Agent 作为第一入口符合主流约定；分析中心是执行层货架，不适合作为「开始研究」的第一落点。

### 想法 3：寻宝鼠作为「科学发现核心」（M2，2027-01-01 启动）的载体 —— 方向正确

用户规划的三项能力与业界共识结构高度对应：

| 用户规划能力 | 业界对应 | 参照 |
|---|---|---|
| 科学推理（Scientific Reasoning）：问题 → 可检验假设 + 可审阅的研究设计 | 假设生成与研究设计 | Google AI Co-Scientist（多 Agent 分任假设生成、批判评估、排序、演化优化，Elo 评分 + 迭代反馈）；FutureHouse Phoenix/Owl |
| 科学验证（Scientific Validation）：评估结果、方法有效性与主张的证据支持 | 批判评估与证据核查 | AI Co-Scientist 的 critical evaluation 角色；FutureHouse 强调透明推理过程对用户可见 |
| 研究演进（Research Evolution）：保存研究知识，提出有证据依据的后续建议 | 演化优化与知识沉淀 | AI Co-Scientist 的 evolutionary optimization；FutureHouse Robin（编排 Crow/Falcon/Finch 为端到端发现工作流，2025-05 完成首个 AI 主导发现：ripasudil 用于干年龄相关性黄斑变性） |

现状基础：寻宝鼠已有「数据发现（探矿定位）、编号溯源（验宝鉴宝）、数据集解读（清点矿藏）、文献探索（翻检文献）」四入口，是科学推理能力的前半段。

关键缺口（M2 施工点，不在本期实施）：
1. **会话产物结构化**：对话产出需落成「假设卡 + 研究设计稿」等可审阅、可交付的产物，而非聊完即散；
2. **验证检查单**：对分析结果/方法/主张的证据支持度评估机制；
3. **跨会话知识沉淀**：研究知识的保存与复用，呼应首页叙事「科研资产积累」。

口径纪律：2027-01-01 前不在 UI 挂「科学发现核心」牌子，先做入口导流与会话产物化；对外叙事（BP/路演）中该能力统一写「规划中」，施工完成一项才把对应文案从「目标」改为「已实现」。

## 三、任务 1：首页 hero 卡片视觉优化

### 提示词（paste-ready）

```text
【任务：首页欢迎卡片视觉优化 —— 在现有首页基础上修改，禁止推倒重写】

先读现有首页组件与样式体系，确认欢迎卡片（hero 区，含"CygnusX BioOps · 天鹅座智能科研平台 / 晚上好，JIAN / 让科学问题，抵达可验证的发现。"与右侧 RESEARCH LIFECYCLE 面板）的实现位置后再动手。

现状问题：卡片使用深蓝紫深色渐变底，与页面整体浅灰白背景（近 #f5f6f8）视觉权重失衡，显得突兀；卡片内次级文字对比度偏低。

修改 spec：
1. 卡片背景改为浅色方案：白底（#ffffff）或极浅品牌色底（如 linear-gradient(135deg, #eef2ff, #f5f3ff)），主标题用深色文字（#1a1a2e 或现有标题色），品牌渐变只保留在装饰元素上（左侧竖条、图标、主按钮、RESEARCH LIFECYCLE 面板的细描边）。
2. 副标题与正文文字对比度满足 WCAG AA（正文 ≥4.5:1）。
3. "开始一项研究"主按钮保持现有品牌实心样式不变；"AI 规划研究方案"次按钮在浅底下用描边样式。
4. 右侧 RESEARCH LIFECYCLE 面板同步改浅：白底/浅底 + 现有品牌色图标，阴影收敛。
5. 不改路由、不改文案、不改布局结构、不动页面其他模块；风格与平台整体浅色工作台基调一致。

验收：首屏截图对比，卡片与下方"我的科研工作台"白卡视觉连续；深色只出现在 logo、按钮、强调色等点缀位置。
```

### 人工验收 checklist

| 操作 | 期望现象 | 不通过处理 |
|---|---|---|
| 打开首页看首屏 | hero 卡片浅色底，与下方白色卡片视觉连续 | 截图退回，要求收敛品牌色使用范围 |
| 检查卡片内文字 | 副标题/正文清晰可读，无灰蒙蒙感 | 用对比度工具抽测，未达 4.5:1 退回 |
| 检查两个按钮 | 主按钮品牌实心、次按钮描边，悬停态正常 | 退回核对样式 |

## 四、任务 2：首页 CTA 指向寻宝鼠

### 提示词（paste-ready）

```text
【任务：首页 CTA 入口调整 —— "开始一项研究"指向寻宝鼠】

先读现有首页 hero 区两个按钮（"开始一项研究""AI 规划研究方案"）的点击处理与路由配置，确认当前跳转目标（分析中心）后再改。

修改 spec：
1. "开始一项研究"点击后跳转到寻宝鼠页面并自动新建一个对话（等价于用户点"新建对话"后的状态），输入框聚焦。
2. "AI 规划研究方案"同样落到寻宝鼠新对话，但预填引导语/激活"方案规划"意图（若寻宝鼠已有意图/模式机制则复用，没有则仅在输入框预填占位提示，不新增后端逻辑）。
3. 分析中心入口不受影响：左侧导航与首页其他入口保持原样。
4. 不改寻宝鼠页面本身的功能逻辑。

验收：从首页点击两个 CTA 均进入寻宝鼠新对话态；浏览器后退可回到首页；分析中心从导航正常可达。
```

### 人工验收 checklist

| 操作 | 期望现象 | 不通过处理 |
|---|---|---|
| 首页点「开始一项研究」 | 进入寻宝鼠新对话，输入框聚焦 | 截图退回，要求核对路由与新对话态 |
| 首页点「AI 规划研究方案」 | 进入寻宝鼠新对话且有方案规划引导 | 若无意图机制，确认至少有预填提示 |
| 浏览器后退 | 回到首页，状态正常 | 退回检查路由栈 |
| 左侧导航进分析中心 | 正常可达，流程列表完整 | 退回检查是否误改导航 |
