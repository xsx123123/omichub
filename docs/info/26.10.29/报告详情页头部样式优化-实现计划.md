# 报告详情页头部样式优化 — 实现计划

> 活文档：CygnusX 平台「结果报告中心 - 报告详情页（BioReport 内嵌）」头部区域样式优化。
> 当前覆盖：Part 1（第 1 轮需求：标题区"X101SC26098749-Z01-J001 分析报告 + 已完成 · 外部交付 · RNA-seq 0.2.0 · 时间"显示样式重排）。

## 背景与目标

报告详情页顶部头部区域已经过多轮微调，用户仍不满意。截图现状：

- 左侧一排灰底按钮：← 报告中心 / 新窗口打开 / 收藏 / 下载；
- 右侧超长项目编号以超大加粗字号充当页面主标题；
- 状态、交付类型、流程版本、时间戳以 "·" 串联成一整行灰色小字，紧贴标题。

目标：对头部做**结构性重排**（信息层级 + 布局分区），而非继续微调字号颜色。

## 问题清单（逐条转 spec）

| # | 现状问题 | 修改 spec |
|---|---|---|
| 1 | 机器 ID 充当主标题：超长编号以超大加粗字号占据视觉中心，可读性差 | 两行式标题组：主标题"分析报告"（有项目名称则用项目名称）20px/600；ID 降为等宽字体 chip（13px、padding 2px 8px、圆角 6px、浅灰底 + 1px 描边、点击复制） |
| 2 | 元信息一长串点分灰字，无层级 | 拆 badge 组：状态=绿色 pill（语义色映射）、外部交付=描边 tag、RNA-seq 0.2.0=中性灰 tag；时间降为 12~13px 灰字置末尾，格式 YYYY-MM-DD HH:mm（省秒）；badge 间距 8px，不再用 "·" 串联 |
| 3 | 操作区与标题区混排，灰底按钮喧宾夺主 | 头部左右两区 flex（高约 64px、垂直居中）：左区=返回文字链接"← 报告中心"（去按钮底）+ 两行式标题组；右区=新窗口/收藏/下载收敛为 icon-only 按钮 + tooltip，hover 有反馈 |
| 4 | 窄屏风险 | 空间不足时标题组在上、操作区在下堆叠；ID chip 过长省略号截断 + tooltip 完整 ID；禁止横向滚动 |

## 约束

- 改已有页面，禁止推倒重写；不动路由、功能逻辑、报告正文深色区与无关组件；不引入新依赖。
- 与平台浅色导航 + 深色报告正文的既有视觉体系一致；文字对比度 ≥ WCAG AA。
- 交互动效 150~250ms，只用 transform/opacity。

## 需要修改的问题（逐条执行）

1. 机器 ID 充当主标题：超长项目编号以超大加粗字号占据头部视觉中心，可读性差。
   将头部标题改为两行式标题组：
   - 第一行：主标题（有项目名称字段用项目名称，否则用"分析报告"），20px / font-weight 600；
     项目 ID 降为辅助信息，用等宽字体 chip 呈现：font-family 等宽（ui-monospace /
     SFMono-Regular / Consolas），13px，padding 2px 8px，border-radius 6px，
     浅色背景下 background: rgba(0,0,0,0.04) + 1px border rgba(0,0,0,0.08)，点击复制 ID。
   - 第二行为 meta badge 行（见第 2 条）。
2. 元信息一长串点分灰字：状态、交付类型、流程版本、时间挤在一行，无层级。拆成 badge 组：
   - 状态 badge：已完成 → 绿色 pill（#52c41a 文字 + rgba(82,196,26,0.1) 底）；其他状态
     按语义映射（进行中=蓝、失败=红等）；
   - 交付类型 tag：外部交付 → 描边 tag（蓝 #1e6fff outline）；
   - 流程版本 tag：RNA-seq 0.2.0 → 中性灰 tag；
   - 时间戳：降为 12~13px 灰字（#8c8c8c）置于 badge 行末尾，格式 YYYY-MM-DD HH:mm
     （秒省略）。
   - badge 间 8px 间距，不再使用 "·" 串联。
3. 操作区与标题区混排、按钮喧宾夺主：头部改为左右两区 flex 布局（高度约 64px，
   align-items: center）：
   - 左区：返回"← 报告中心"改为纯文字链接样式（去掉灰底按钮样式）+ 两行式标题组；
   - 右区：新窗口打开 / 收藏 / 下载 收敛为 icon-only 按钮（带 tooltip），hover 给出
     明确反馈（background: rgba(0,0,0,0.04)）。
   - 收藏、下载、新窗口打开功能行为与改前完全一致。
4. 窄屏适配：空间不足时标题组与操作区上下堆叠（标题组在上），不出现横向滚动；
   ID chip 过长时省略号截断 + tooltip 显示完整 ID。

## 全局约束

- 与平台浅色导航 + 深色报告正文的既有视觉体系保持一致；头部保持浅色背景。
- 文字对比度不低于 WCAG AA（4.5:1）。
- 交互动效 150~250ms，只用 transform / opacity，尊重 prefers-reduced-motion。

## 验收标准（逐条自检）

- [ ] ID 不再以大号加粗标题形态出现，主标题 / ID chip / meta badge 三层级清晰
- [ ] 状态、交付类型、流程版本为独立 badge，时间为灰字，不再用 "·" 串联
- [ ] 返回为文字链接，右侧三个操作为 icon + tooltip
- [ ] 桌面与约 768px 窄屏下布局不破损、无横向滚动
- [ ] 返回、新窗口打开、收藏、下载功能与改前完全一致
- [ ] 深色报告正文区零改动
