# CygnusX 首页视觉优化实现计划

> 版本：v1.0（2026-10-21）
> 范围：控制台首页（Hero 横幅 → 公告条 → 我的科研工作台 → 科研快捷入口 → Agent × Skill × Flow → 四大技术支柱 → 科研生态 → 系统管理）
> 性质：**在现有页面上优化，不是重新设计**。禁止推倒重写、禁止改路由/功能逻辑/数据请求。

---

## 一、背景与目标

首页信息架构清楚（Hero → 工作台 → 快捷入口 → 能力叙事 → 生态 → 系统管理），问题集中在两点：

1. **首屏效率低**：Hero 占约 55% 视高且中部留空，高频的「我的科研工作台」被挤出首屏；
2. **视觉细节粗糙**：标题断词、三列不等宽、状态标签区分度低、品牌色不统一。

目标：不动信息架构，用一轮样式迭代把首屏效率和细节质感拉齐。

## 二、详细优化清单（按优先级）

### P0 首屏问题（最先改，收益最大）

| # | 位置 | 现状问题 | 具体修改 spec | 预期效果 |
|---|------|---------|--------------|---------|
| 1 | Hero 主标题 | 「让科学问题，抵达可验证的发/现。」在"发现"中间断行，句号险些单独挂行 | 用 `<br>` 或 white-space 把断点固定在「让科学问题，」之后；容器加 `text-wrap: balance` 兜底；字号改 `clamp()` 保证 1280~2560px 下两行内排完不拆词 | 首屏第一眼文案完整、断行有设计感 |
| 2 | Hero 整体高度 | 约占 55% 视高，中部大面积留空，工作台被挤出首屏 | `min-height` 降至 360~400px；上下 padding 收紧至 40~48px；按钮区与底部 slogan 间距同步压缩 | 1440px 视高下「我的科研工作台」标题进入首屏 |
| 3 | Hero 内 RESEARCH LIFECYCLE 玻璃卡 | 紫底上副文字偏灰，对比度不足 | 卡片背景 `rgba(255,255,255,0.10)` + `backdrop-filter: blur(16px)`；边框 `1px solid rgba(255,255,255,0.18)`；主文字 `#FFF`，副文字 `rgba(255,255,255,0.85)` | 文字清晰可读，对比度 ≥ 4.5:1 |
| 4 | 公告条（RNA-seq / ATAC-seq 已就绪） | 与 Hero 两块紫色渐变紧贴糊成一片；关闭后刷新又出现 | 与 Hero 之间留 16px 间距；关闭写入 `localStorage`（key 如 `announcement:rna-atac-ready:dismissed`），内容变更才重新出现 | 视觉分层清楚，公告不骚扰 |

## 三、实施顺序

- **Phase 1（P0，#1~4）**：首屏四件事，一次改完一起看效果——改动小、视觉收益最大。
- **Phase 2（P1，#5~8）**：工作台网格与 badge 体系；#7 的状态核查只出不改样式的结论。
- **Phase 3（P2，#9~12）**：品牌色、hover 层级、积分胶囊、动效规范收尾。
- **Phase 4（P3，#13~14，可选）**：导航分组与页面节奏，确认要做再开工。

## 需要修改的问题（逐条执行）

1. Hero 主标题断行不当：「让科学问题，抵达可验证的发现。」目前在"发/现"中间断行，
   词被拆开。修改方案：用 <br> 或 white-space 控制断点在「让科学问题，」之后；
   标题容器加 text-wrap: balance 兜底；font-size 改用 clamp() 保证 1280~2560px
   宽度下都在两行内排完且不拆词。

2. Hero 过高挤压首屏：当前横幅约占 55% 视高且中部大面积留空。将 Hero 的
   min-height 降至 360~400px，上下 padding 收紧至 40~48px；「开始一项研究」
   「让 Agent 帮我规划」两个按钮与底部 slogan 的间距同步压缩。目标：1440px
   高度视口下，「我的科研工作台」标题在首屏内可见。

3. RESEARCH LIFECYCLE 玻璃卡对比度不足：紫底上副文字偏灰。卡片背景改为
   rgba(255,255,255,0.10) + backdrop-filter: blur(16px)，边框
   1px solid rgba(255,255,255,0.18)；主文字 #FFFFFF，副文字
   rgba(255,255,255,0.85)，确保对比度 ≥ 4.5:1。

4. 公告条加关闭记忆：点击关闭按钮后写入 localStorage（key 如
   announcement:rna-atac-ready:dismissed），同一会话/后续访问不再显示；
   公告内容更新（key 变更）时才重新出现。视觉上与 Hero 之间留 16px 间距，
   不要两块渐变紧贴。

5. 工作台三列不等宽：改为 grid-template-columns: repeat(3, minmax(0, 1fr))，
   列内长标题（如报告名）单行省略 text-overflow: ellipsis。1280px 以下宽度
   降级为单列堆叠。

6. 状态标签统一为 badge 体系：运行中 = 蓝（如 #4C8DFF 底 12% 透明度 + 文字
   #7FB0FF），已完成 = 绿（#34D399 系），已过期 = 灰但文字对比度 ≥ 4.5:1；
   三种状态共用同一 badge 组件类，尺寸/圆角/字重一致。

7. 品牌色统一：「系统管理」卡片的「进入管理」按钮当前是蓝绿渐变，改为与整站
   一致的蓝紫主色渐变（取 Hero 或主按钮的既有色值），hover 态给出明确反馈
   （亮度提升或 translateY(-1px)）。

8. 卡片层级区分：高频操作区（科研工作台三列、快捷入口）卡片 hover 时
   translateY(-2px) + 柔和阴影（0 8px 24px rgba(0,0,0,0.35)），过渡 200ms；
   展示型区块（四大技术支柱、科研生态）保持静态。动画只用 transform/opacity，
   尊重 prefers-reduced-motion（开启时降级为无动效）。

9. 顶部积分胶囊：「26732.3」与背景装饰图形疑似重叠，给胶囊容器增加
   padding: 4px 12px，确认数字完整显示且不与铃铛/头像间距拥挤。

10. （顺手核查，非样式）运行任务列表中 10月3日 的任务至今显示「运行中」，
    请检查任务状态回写逻辑：是真实在跑、还是状态同步丢失的僵尸任务。只查并
