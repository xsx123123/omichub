# 节日彩蛋 · 全屏沉浸式物候背景动效升级方案 V2

> 设计角色：Apple 资深前端架构师 & 东方美学动效专家
> 目标：让每一个节日/节气拥有“一节一貌”的专属全屏背景，拒绝套娃、拒绝高饱和、拒绝廉价粒子。

## 一、升级核心原则

1. **一节一貌（One Festival, One Form）**  
   背景不再靠关键词兜底，而是按 `festival.id` 或 `phenology` 显式路由到专属渲染器。形状、色彩、律动、肌理全部独立。

2. **Z 轴深度分层**  
   背景拆成三层：
   - **Layer-3 环境基底**：极大模糊（26–60px）的缓慢流体渐变，占 50% 视觉权重，但不抢内容。
   - **Layer-2 物候意象**：中等模糊（8–18px）的抽象几何/植物/天象线条，做呼吸动画。
   - **Layer-1 微光散景**：极小/无模糊的微粒子或光斑，提供细腻的高频细节。

3. **物理弹簧化所有运动**  
   禁止 `linear`；所有周期性运动使用正弦缓变 + 鼠标视差 lerp。入场使用弹簧参数：`mass / stiffness / damping`。

4. **低饱和中国传统色**  
   主色控制在 HSL 饱和度 ≤ 35%，明度压暗；高光只做点缀，避免大红大绿。

5. **东方微观肌理**  
   每个节日在弹窗层面已有 `texture`，背景层通过 Canvas 噪点/网格/裂纹与之呼应，但不重复。

## 二、现有节日专属背景方案

### 1. 春节 · `spring_festival`
**精神内核**：辞旧迎新、暗涌星火、爆竹余烬。

- **中国传统色盘**
  - 霁红（主底）：`#1A0505` —— 深沉祭红，压得住年味。
  - 琉璃金（高光）：`#D8B46A`
  - 朱红（点缀）：`#8C3B3B`

- **抽象文化符号**
  - 不贴灯笼、不放胖娃娃。提取“爆竹余烬”与“春联飞白”。
  - 几何化：底部升起极细的垂直金色粒子（像未散的火药星尘），顶部有缓慢展开的横向飞白。

- **全屏沉浸式背景**
  - Layer-3：极暗红色径向渐变缓慢脉动，模拟祭红釉在暗处的呼吸。
  - Layer-2：稀疏的金箔碎屑粒子（8–12 个）以不同深度缓慢上升，带尾迹拖影。
  - Layer-1：底部 1/5 处升起极淡的垂直“余烬”线，高度随机，周期 6–10s。

- **动效编排**
  - 入场：`modalSpringIn`（mass 1, stiffness 300, damping 25），弹窗如卷轴般带阻尼上浮。
  - 静谧：金箔粒子 12s 周期呼吸，亮暗 0.2 → 0.45。
  - 交互：鼠标移动时背景散景反向漂移，系数 0.3 / 0.5 / 0.8 按深度分层。

### 2. 元宵节 · `lantern_festival`
**精神内核**：灯火阑珊、星雨坠落、暖光团圆。

- **中国传统色盘**
  - 缃叶（暖底）：`#2D1F12`
  - 灯芯橙（高光）：`#C9985A`
  - 月白（点缀）：`#E3D5C3`

- **抽象文化符号**
  - 不画灯笼。提取“灯影在湖面形成的同心圆光晕”与“暖光上升”。
  - 几何化：屏幕下半部是横向拉长的椭圆光斑（湖面倒影），上半部是缓缓上升的暖色光点。

- **全屏沉浸式背景**
  - Layer-3：深褐底色上，缓慢移动的暖橙径向光晕（模拟灯笼照在雾气中）。
  - Layer-2：7 个横向椭圆“水晕”以不同相位呼吸，暗示水面灯影。
  - Layer-1：零星暖白光点以正弦轨迹缓慢上升，像孔明灯远去。

- **动效编排**
  - 入场：`modalWaterIn`（mass 1.2, stiffness 260, damping 30），如水波荡漾展开。
  - 静谧：光晕 10s 周期明暗交替，光点上升速度 0.3–0.6px/s。
  - 交互：悬停按钮时，最近光点产生 0.5s 弹簧收缩（stiffness 400, damping 20）。

### 3. 端午节 · `dragon_boat`
**精神内核**：龙舟竞渡、粽叶绿、水纹急。

  - 粽叶绿（高光）：`#84A78B`
  - 龙舟木（点缀）：`#5C4A34`

- **抽象文化符号**

  - 几何化：斜向掠过的水痕线条 + 底部漂浮的横向叶脉。

- **全屏沉浸式背景**
  - Layer-3：深青绿底色，缓慢水平漂移的墨绿色光带。

  - Layer-1：底部淡绿色叶脉纹理，缓慢左右平移。

- **动效编排**

  - 静谧：水痕每 12–18s 划过一条，速度带缓入缓出。
  - 交互：鼠标左右移动，叶脉层反向平移，产生船行水上的视差。

- **抽象文化符号**

## 三、24 节气专属物候背景方案

24 节气复用春/夏/秋/冬四个基础主题，但通过 `phenology` 注入独立背景意象。

| 节气 | phenology | 核心意象 | 主渲染器 |
|---|---|---|---|
| 立春 | spring-sprout | 嫩芽破土 | 底部 7 株嫩芽形贝塞尔曲线，缓慢生长呼吸 |
| 雨水 | rain-ripple | 雨滴落湖 | 顶部下落雨线 + 湖面同心圆水纹 |
| 惊蛰 | thunder-crack | 春雷裂空 | 稀疏闪电折线 + 底部萌发芽点 |
| 春分 | equinox-balance | 昼夜均分 | 左右对称光带 + 横向天平弧线 |
| 清明 | clear-rain | 斜雨纷纷 | 倾斜雨线 + 底部淡烟 |
| 谷雨 | rice-rain | 稻雨润谷 | 斜雨 + 底部稻穗轮廓 |
| 立夏 | tomato-vine | 藤蔓延展 | 底部藤蔓曲线 + 椭圆叶片 |
| 小满 | rice-wheat-fill | 麦粒灌浆 | 底部麦穗线条，籽粒饱满呼吸 |
| 芒种 | wheat-awn-seed | 麦芒初露 | 麦穗 + 尖锐芒刺 |
| 夏至 | solar-arc | 日轨最高 | 顶部巨大弧形光带，正午阳光 |
