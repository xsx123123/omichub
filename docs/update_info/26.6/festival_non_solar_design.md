## 一、春节 `spring_festival`

### 1. 视觉基调与专属文化符号

- **中国传统色盘**
  - 霁红（主底）`#1A0505`：深沉祭红，压住年味，不艳不浮。
  - 琉璃金（高光）`#D8B46A`：如故宫琉璃瓦在暗光中的微芒。
  - 朱红（点缀）`#8C3B3B`：爆竹燃尽后的余烬色。

- **抽象文化符号**
  - 拒绝红灯笼、胖娃娃、福字剪贴画。
  - 提取“爆竹余烬”与“春联飞白”：底部升起极细的金色垂直粒子，象征未散的火药星尘；顶部有缓慢展开的横向飞白，象征春联被风轻轻掀开一角。
  - 几何化：垂直短线（余烬）+ 横向弧线（飞白），全部用 1px 级线条表达。

- **形态与专属肌理**
  - 弹窗形态 `scroll`（卷轴），圆角 34px/18px 交替，仿春联横批。
  - 专属肌理 `brocade`（锦缎暗纹）：极淡的 45° 斜纹 + 径向噪点，与毛玻璃叠加。

### 2. 全屏沉浸式物候背景

- **Layer-3 环境基底**：极暗红色径向渐变缓慢脉动，模拟霁红釉在暗处的呼吸，周期 18s。
- **Layer-2 物候意象**：8–12 个金箔碎屑粒子以不同深度缓慢上升，带尾迹拖影，速度 0.3–0.6px/s。
- **Layer-1 微光粒子**：底部 1/5 处升起极淡的垂直“余烬”线，高度随机，周期 6–10s，alpha 0.08–0.18。

### 3. 高级动效编排

- **A. 东方韵味入场**
  - 弹窗如卷轴自上而下缓缓展开：`modalSpringIn`，物理参数 `mass: 1, stiffness: 300, damping: 25`。
  - 背景金色粒子延迟 0.3s 后从底部升起，营造“爆竹声后，星火未散”的时间差。

- **B. 静谧流转**
  - 金箔粒子 12s 周期呼吸，亮暗 0.2 → 0.45。
  - 顶部飞白横向漂移，18s 周期，位移 ±6px。
  - 弹窗边缘琉璃金内发光 8s 周期缓慢强弱更替。

- **C. 阻尼交互**
  - 鼠标移动时，背景散景按深度分层反向漂移：深度 0.3 层系数 0.25，深度 0.7 层系数 0.55，余烬线系数 0.8。
  - 悬停领取按钮时，最近的金箔粒子产生 0.5s 弹簧收缩：`stiffness: 400, damping: 20`。

### 4. 核心前端实现

```ts
// 弹簧参数
const spring = { mass: 1, stiffness: 300, damping: 25 }

// Canvas 关键片段：余烬线
for (let i = 0; i < 12; i++) {
  const progress = (time * speed + offset) % 10
  const t = progress / 10
  const y = baseY - t * height
  ctx.strokeStyle = rgba(gold, (1 - t) * alpha)
  ctx.lineWidth = 0.8 + rnd * 1.2
  ctx.beginPath(); ctx.moveTo(x, y); ctx.lineTo(x, y - height * 0.18); ctx.stroke()
}
```

## 二、元宵节 `lantern_festival`

### 1. 视觉基调与专属文化符号

- **中国传统色盘**
  - 缃叶（主底）`#2D1F12`：深褐如旧书页，托住暖光。
  - 灯芯橙（高光）`#C9985A`：如灯笼芯火的低饱和暖橙。
  - 月白（点缀）`#E3D5C3`：远处孔明灯的冷白微光。

- **抽象文化符号**
  - 拒绝具象灯笼。
  - 提取“灯影在湖面形成的同心圆光晕”与“暖光上升”。
  - 几何化：屏幕下半部是横向拉长的椭圆光斑（湖面倒影），上半部是缓缓上升的暖色光点（远去的天灯）。

- **形态与专属肌理**
  - 弹窗形态 `ripple`（涟漪圆角），边框柔和如水面倒影。
  - 专属肌理 `silk`（丝绸暗纹）：细腻横向波纹，呼应湖面。

### 2. 全屏沉浸式物候背景

- **Layer-3 环境基底**：深褐底色上，缓慢移动的暖橙径向光晕，模拟灯笼照在雾气中。
- **Layer-2 物候意象**：7 个横向椭圆“水晕”以不同相位呼吸，暗示水面灯影，rx 60–150px，ry 18–32px。
- **Layer-1 微光粒子**：零星暖白光点以正弦轨迹缓慢上升，像孔明灯远去，速度 0.3–0.6px/s。

### 3. 高级动效编排

- **A. 东方韵味入场**
  - `modalWaterIn`，物理参数 `mass: 1.2, stiffness: 260, damping: 30`。
  - 弹窗如水波荡漾展开，底部水晕先浮现，天灯光点后升起。

- **B. 静谧流转**
  - 水晕 10s 周期明暗交替，alpha 0.04 → 0.1。
  - 天灯光点上升周期 12–18s，到顶部后淡出重生。

- **C. 阻尼交互**
  - 鼠标悬停按钮时，最近光点产生 0.5s 弹簧收缩：`stiffness: 400, damping: 20`。
  - 鼠标左右移动，水晕层产生 0.4 视差，光点层产生 0.6 视差。

### 4. 核心前端实现

```ts
const spring = { mass: 1.2, stiffness: 260, damping: 30 }

// 水晕
strokeArc(ctx, x, y, rx * breathe, ry * breathe, 0, 0, Math.PI * 2, color, 0.06)

// 天灯上升
const py = h * (0.9 - t * 0.75)
ctx.fillStyle = rgba(color, (1 - t) * 0.15)
ctx.arc(x + Math.sin(time * 0.2 + i) * 12, py, radius, 0, Math.PI * 2)
```

## 三、端午节 `dragon_boat`

### 1. 视觉基调与专属文化符号

  - 龙舟木（点缀）`#5C4A34`：隐约的木色水痕。

- **抽象文化符号**
  - 拒绝龙舟、粽子剪贴画。
  - 提取“竞渡时水面的 V 形尾迹”与“粽叶的平行叶脉”。
  - 几何化：斜向掠过的水痕线条 + 底部漂浮的横向叶脉。

- **形态与专属肌理**
  - 弹窗形态 `jade`（玉璧切角），圆角 44px/20px。
  - 专属肌理 `bamboo`（竹节暗纹）：竖向淡纹，节骨处有微光。

### 2. 全屏沉浸式物候背景

- **Layer-3 环境基底**：深青绿底色，缓慢水平漂移的墨绿色光带。
- **Layer-2 物候意象**：3–4 组斜向“水痕”从屏幕一侧划过，模拟龙舟桨迹，12–18s 一条。
- **Layer-1 微光粒子**：底部淡绿色叶脉纹理，缓慢左右平移。

### 3. 高级动效编排

- **A. 东方韵味入场**
  - `modalWaterIn`，物理参数 `mass: 1.3, stiffness: 280, damping: 32`。
  - 带水波张力感，仿佛弹窗从水面浮出。

- **B. 静谧流转**
  - 水痕每 12–18s 划过一条，速度带缓入缓出（ease-in-out）。
  - 叶脉层 16s 周期左右平移 ±8px。

- **C. 阻尼交互**
  - 鼠标左右移动，叶脉层反向平移，产生船行水上的视差。
  - 水痕经过鼠标附近时受轻微“排斥”，alpha 瞬间降低 20%。

### 4. 核心前端实现

```ts
const spring = { mass: 1.3, stiffness: 280, damping: 32 }

// 水痕
const startX = -w * 0.2 + t * w * 1.4
ctx.strokeStyle = rgba(green, alpha)
ctx.lineWidth = 2 + rnd * 2
ctx.moveTo(startX, y); ctx.lineTo(startX + w * 0.18, y - h * 0.06); ctx.stroke()
```
