## 五、问题优先级与修复建议

### 5.1 严重问题（建议立即修复）

1. **登录后页面不跳转**
   - 建议：检查登录成功后的路由跳转逻辑，确保调用 `router.push('/')` 或等效导航方法
   - 补充：确认 token 写入 localStorage 后再执行跳转，避免竞态条件

2. **SPA 内部路由无权限检查**
   - 建议：在路由守卫（beforeEach）中添加全局权限检查，每次路由切换时验证 token 有效性
   - 补充：未登录用户访问任何受保护路由应统一重定向到 `/login`

3. **任务中心页面完全空白**
   - 建议：检查 `/tasks` 路由对应的组件是否正确注册和渲染，检查是否有 JS 报错导致组件未挂载

4. **数据管理页面内容错误**
   - 建议：检查 `/files` 路由的组件映射，确保指向正确的文件管理组件而非关于页面

### 5.2 中等问题（建议尽快修复）

5. **分析流程中心页面未实现**：完成 `/flows` 页面的独立内容开发
6. **实验室知识库链接错误**：修正顶部导航"实验室知识库"的链接目标
7. **分析中心子菜单**：为各分析类型创建独立页面或统一入口页
8. **退出登录功能**：添加清除 token 并跳转登录页的逻辑
9. **错误密码提示**：添加登录失败时的错误提示（如 Toast 或表单错误信息）
10. **最后登录时间**：在用户登录成功后更新数据库中的最后登录时间字段
11. **平台注册开关控制**：
    - 建议：在系统管理后台添加"平台设置"或"全局配置"页面，包含"开放注册"开关（Switch/Toggle）
    - 后端：添加 `site_settings` 表或配置项，存储 `registration_enabled` 布尔值
    - 前端：注册页面加载时先请求该配置，若关闭则隐藏注册按钮或显示"暂不接受新用户注册"提示
    - 权限：仅管理员（admin）角色可查看和修改此设置

### 5.3 AI 助手问题修复建议

12. **对话消息不显示**：检查 AI 助手组件的消息列表渲染逻辑，确认发送消息后是否正确将消息追加到对话数组并触发重新渲染。当前 DOM 中完全找不到消息内容，说明消息数据未正确写入状态或模板未绑定
13. **模型选择下拉无响应**：检查模型选择组件的点击事件绑定和下拉菜单展开逻辑，确认选项数据是否正确加载
14. **快捷提示卡片无响应**：为快捷提示卡片添加点击事件，点击后自动将提示文本填入输入框或触发发送
15. **新建会话按钮**：后端会话创建逻辑正常（会话计数增加），但前端 UI 未正确响应。检查 Vue 状态更新后是否正确切换当前会话并渲染空白对话界面
16. **代码沙盒 404**：该功能页面未实现，需要创建对应的 `/codebox` 或等效路由页面，或暂时从菜单中移除该入口
17. **左侧功能菜单**：检查插件、分析流程、项目数据、深度研究等菜单的点击事件和路由跳转逻辑，确保与正确的功能页面对应
18. **AI 助手整体建议**：AI 助手模块存在严重的 Vue 状态管理问题。建议检查：
    - 发送消息事件是否正确绑定到 `sendMessage()` 方法
    - 消息状态数组是否正确声明为响应式（`ref`/`reactive`）
    - 历史会话列表点击事件是否正确绑定到 `switchConversation()` 方法
    - 各功能按钮的 `@click` 事件是否正确指向对应的方法处理函数
    - 后端 API 接口是否已实现（聊天接口、模型列表接口等）

## 六、测试结论

OmicHub 多组学分析平台目前处于**早期开发阶段**，基础框架（登录、注册、首页、用户管理）已搭建完成，但存在以下核心问题需要优先解决：

1. **登录后路由跳转失败**是最影响用户体验的问题
2. **SPA 内部路由权限缺失**存在安全风险
3. **多个功能页面（任务中心、数据管理、分析流程中心）内容未正确渲染或缺失**
4. **平台缺少注册开关控制**，管理员无法管控用户注册
5. **AI 助手存在严重的 Vue 状态管理问题**：页面 UI 框架完整，但几乎所有交互功能不可用（消息发送不显示、模型选择无响应、快捷提示无响应、历史会话无法切换、代码沙盒跳转404）。后端部分逻辑已运行（新建会话计数增加），但前端状态未正确更新

**建议修复优先级**：
1. 🔴 立即修复：登录跳转、路由权限、任务中心/数据管理页面渲染
2. 🟡 尽快修复：退出登录、错误提示、注册开关控制、最后登录时间
3. 🟢 后续优化：AI 助手 Vue 状态管理修复、分析流程中心内容、实验室知识库页面、代码沙盒功能开发

**AI 助手专项建议**：AI 助手模块是问题最集中的区域，建议优先排查 Vue 组件中各交互事件的 `@click` 绑定和状态管理逻辑，确认 `sendMessage()`、`switchConversation()`、`createNewChat()` 等核心方法是否正确实现和绑定。

建议在继续开发新功能之前，优先修复上述路由跳转和权限控制问题，确保基础功能稳定后再扩展其他模块。
