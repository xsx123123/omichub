## 一、执行摘要与核心决策

### 1.1 功能定位
在 OmicHub 生信工具箱中新增「系统发育树构建工具」，支持从多序列比对(MSA)到系统发育树构建、Bootstrap评估、交互式可视化与美化的完整流程。

### 1.2 五大核心决策

| 决策项 | 决策结论 | 理由 |
|--------|---------|------|
| **计算模式** | 全部计算步骤投递 Celery 异步执行 | MSA/ML树构建均远超5秒阈值，必须异步 |
| **任务拆分** | 单任务 + 内部四阶段进度报告 | MSA→树构建→Bootstrap是强依赖链，无法并行 |
| **前端可视化** | phylotree.js (基于 D3.js) | 唯一支持Newick/分支长度/Bootstrap/重定根的专业库 |
| **Docker策略** | 单镜像 + 双Worker队列 | `omichub/phylo-toolkit` 镜像，标准队列+高内存队列 |
| **进度报告** | Celery `update_state(PROGRESS)` | 四阶段: ALIGNING → BUILDING → BOOTSTRAPPING → FORMATTING |

### 1.3 数据流概要

```
用户上传FASTA ──▶ Web服务器(同步验证, <3s) ──▶ Celery投递 ──▶ Worker容器
                                                                  │
前端轮询 ◀── 返回task_id ◀── 同步API ◀── Redis结果后端 ◀── 4阶段进度报告
  │
  ▼
获取Newick ──▶ phylotree.js渲染 ──▶ 交互式可视化(矩形/圆形/径向)
```

## 三、生物信息学流程与计算复杂度

### 3.1 完整分析流程

```
输入文件(FASTA/Phylip/NEXUS)
    │
    ▼ 同步: 输入验证(<3s)
格式检查/序列数上限/长度一致性/自动检测DNA or Protein
    │
    ▼ Celery: Phase 1 "ALIGNING" (进度0%→35%)
┌─────────────────────────┐
│   多序列比对(MSA)        │
│   MAFFT / ClustalOmega   │
│   / MUSCLE5 (可选跳过)   │
│   复杂度: O(n^2·L)~      │
│   100seq: 5-30s          │
│   1000seq: 1-20min       │
└─────────────────────────┘
    │
    ▼ Celery: Phase 2 "BUILDING" (进度35%→80%)
┌─────────────────────────┐
│   系统发育树构建         │
│   NJ/UPGMA: O(n^3)       │
│   FastTree: O(n·L·log n) │
│   IQ-TREE: O(n^3·L)      │
│   MrBayes: O(n·iter·L)   │
│   100seq: 1s~30min       │
│   1000seq: 10s~2h        │
└─────────────────────────┘
    │
    ▼ Celery: Phase 3 "BOOTSTRAPPING" (进度80%→95%, 可选)
┌─────────────────────────┐
│   Bootstrap评估          │
│   标准: ×100~1000        │
│   UFBoot(IQ-TREE): ×5-10 │
│   MrBayes: 内置(跳过)    │
│   100seq: 5s~10min       │
└─────────────────────────┘
    │
    ▼ Celery: Phase 4 "FORMATTING" (进度95%→100%)
┌─────────────────────────┐
│   结果格式化输出         │
│   Newick(必出)           │
│   NEXUS/PhyloXML/JSON(选)│
│   统计信息JSON           │
│   复杂度: O(n), <2s      │
└─────────────────────────┘
    │
    ▼ 返回前端
Newick字符串 → phylotree.js渲染 → 交互式可视化
```

### 3.2 计算复杂度与执行模式决策

| 步骤 | 算法复杂度 | 100条序列 | 1000条序列 | 内存占用 | **执行模式** |
|------|-----------|-----------|------------|---------|-------------|
| 输入验证 | O(n·L) | <1s | <3s | ~10MB | **Web同步** |
| 序列预处理 | O(n·L) | <1s | <2s | ~50MB | **Web同步** |
| MAFFT比对 | O(n²·L) | 5-15s | 2-10min | 100MB-2GB | **Celery异步** |
| ClustalOmega | O(n·log n·L) | 3-10s | 1-5min | 100MB-1GB | **Celery异步** |
| MUSCLE5 | O(n²·L²) | 10-30s | 5-20min | 200MB-4GB | **Celery异步** |
| Neighbor-Joining | O(n³) | <1s | 10-60s | 50MB-500MB | **Celery异步** |
| FastTree | O(n·L·log n) | 5-30s | 2-10min | 200MB-2GB | **Celery异步** |
| IQ-TREE | O(n³·L) | 30s-5min | 10min-2h | 500MB-8GB | **Celery异步** |
| MrBayes | O(n·iter·L) | 5-30min | 1-8h | 500MB-4GB | **Celery异步** |
| Bootstrap | 倍数×树构建 | 5×树构建 | 5×树构建 | 同树构建 | **Celery异步** |
| 结果格式化 | O(n) | <1s | <2s | ~20MB | **Celery任务内** |

### 3.3 支持的构建方法矩阵

**MSA工具选择：**

| 工具 | 适用场景 | 序列数上限 | 速度 | 精度 |
|------|---------|-----------|------|------|
| **MAFFT** | 通用首选 | ≤30,000 | ★★★★★ | ★★★★☆ |
| **ClustalOmega** | 大规模序列 | ≤100,000 | ★★★★★ | ★★★☆☆ |
| **MUSCLE5** | 高精度需求 | ≤20,000 | ★★★☆☆ | ★★★★★ |

**树构建方法：**

| 方法 | 类型 | 速度 | 精度 | 特殊功能 |
|------|------|------|------|---------|
| **Neighbor-Joining** | 距离法 | 快 | 中 | 大规模初步聚类 |
| **UPGMA** | 距离法 | 快 | 低 | 等速率假设/教学 |
| **FastTree** | 近似ML | 很快 | 中高 | ≤10⁴序列 |
| **IQ-TREE** | 精确ML | 中 | 高 | ModelFinder+UFBoot |
| **MrBayes** | 贝叶斯 | 慢 | 很高 | 后验概率(PP) |

**进化替代模型：**

| 模型 | 参数数 | 适用数据 | 说明 |
|------|--------|---------|------|
| **JC69** | 0 | DNA | 最简单，等概率替换 |
| **K2P** | 1 | DNA | 转换/颠换比率 |
| **HKY** | 4+n | DNA | 考虑碱基频率 |
| **GTR** | 8+n | DNA | 最灵活(推荐) |
| **+G / +I** | +1~2 | DNA/蛋白 | Gamma分布/不变位点 |
| **LG / WAG** | 0 | 蛋白质 | 蛋白质分析默认 |

## 四、后端架构实现

### 4.1 Celery任务设计

**决策: 单任务模式，内部4阶段进度报告**

```python
# tasks/phylo_tree.py

from celery import shared_task, current_task
from celery.exceptions import SoftTimeLimitExceeded

TASK_TIMEOUT = 3600 * 2       # 2小时硬超时
TASK_SOFT_TIMEOUT = 3600      # 1小时软超时

# 阶段权重(用于进度计算)
PHASE_WEIGHTS = {
    "alignment": 0.35,        # MSA占35%
    "tree_building": 0.40,    # 树构建占40%
    "bootstrap": 0.20,        # Bootstrap占20%
    "formatting": 0.05,       # 格式化占5%
}

@shared_task(
    bind=True,
    name="omichub.phylo.build_tree",
    time_limit=TASK_TIMEOUT,
    soft_time_limit=TASK_SOFT_TIMEOUT,
    max_retries=2,
    queue="phylo_tree",       # 专用队列
)
def build_phylogenetic_tree(self, task_input: dict) -> dict:
    """
    系统发育树构建主任务
    完整流程: MSA → 树构建 → Bootstrap → 结果格式化
    """
    task_id = self.request.id
    start_time = time.time()
    phases_completed = []
    
    try:
        work_dir = Path(tempfile.mkdtemp(prefix=f"phylo_{task_id}_"))
        
        # ═══ PHASE 1: 多序列比对 ═══
        if task_input["alignment_tool"] != "none":
            _update_progress(self, "ALIGNING", 0.05, "开始多序列比对...")
            # 调用MAFFT/ClustalO/MUSCLE5
            run_alignment(task_input, work_dir, 
                callback=lambda p, msg: _update_progress(
                    self, "ALIGNING", 0.05 + p * PHASE_WEIGHTS["alignment"], msg
                )
            )
            phases_completed.append("alignment")
        else:
            phases_completed.append("alignment_skipped")
        
        # ═══ PHASE 2: 进化树构建 ═══
        _update_progress(self, "BUILDING", 0.40, "开始构建进化树...")
        run_tree_building(task_input, work_dir,
            callback=lambda p, msg: _update_progress(
                self, "BUILDING", 0.40 + p * PHASE_WEIGHTS["tree_building"], msg
            )
        )
        phases_completed.append("tree_building")
        
        # ═══ PHASE 3: Bootstrap ═══
        if task_input.get("bootstrap_enabled") and \
           task_input["tree_method"] in ["nj", "upgma", "iqtree"]:
            _update_progress(self, "BOOTSTRAPPING", 0.80, "开始Bootstrap评估...")
            run_bootstrap(task_input, work_dir,
                callback=lambda p, msg: _update_progress(
                    self, "BOOTSTRAPPING", 0.80 + p * PHASE_WEIGHTS["bootstrap"], msg
                )
            )
            phases_completed.append("bootstrap")
        else:
            phases_completed.append("bootstrap_skipped")
        
        # ═══ PHASE 4: 结果格式化 ═══
        _update_progress(self, "FORMATTING", 0.95, "格式化输出结果...")
        output_files = format_results(task_input, work_dir)
        phases_completed.append("formatting")
        
        # 计算统计信息
        tree_stats = compute_tree_statistics(output_files["newick"])
        
        _update_progress(self, "COMPLETED", 1.0, "任务完成!")
        
        return {
            "task_id": task_id,
            "status": "COMPLETED",
            "output_files": output_files,
            "statistics": tree_stats,
            "execution_time": round(time.time() - start_time, 2),
            "phases_completed": phases_completed,
        }
        
    except SoftTimeLimitExceeded:
        return {"status": "FAILED", "error": "任务执行超时", "phases_completed": phases_completed}
    except Exception as e:
        return {"status": "FAILED", "error": str(e), "phases_completed": phases_completed}


def _update_progress(task, phase: str, progress: float, message: str):
    """更新Celery任务进度"""
    task.update_state(
        state="PROGRESS",
        meta={
            "phase": phase,                    # ALIGNING/BUILDING/BOOTSTRAPPING/FORMATTING
            "progress": round(progress, 4),    # 0.0 ~ 1.0
            "message": message,
            "timestamp": time.time(),
        }
    )
```

**任务状态流转：**

```
PENDING ──Worker领取──▶ ALIGNING ──MSA完成──▶ BUILDING ──树构建完成──▶ BOOTSTRAPPING
                                                              │
                                                        (MrBayes/无Bootstrap时跳过)
                                                              │
                                                              ▼
                                    COMPLETED ◀── 格式化完成 ── FORMATTING ◀── Bootstrap完成
                                       │
                                       ▼
                                前端获取Newick → 渲染树
```

// 前端 Vue 3 轮询逻辑
const POLLING_INTERVAL = 2000;

function startPolling(taskId) {
  const timer = setInterval(async () => {
    const resp = await fetch(`/api/phylo/tasks/${taskId}/status`);
    const data = await resp.json();
    
    if (data.status === "PROGRESS") {
      // 更新进度条 UI
      updateProgress(data.phase, Math.round(data.progress * 100), data.message);
    } else if (data.status === "SUCCESS") {
      clearInterval(timer);
      // 获取Newick并渲染树
      renderTree(data.result.output_files.newick);
    } else if (data.status === "FAILURE") {
      clearInterval(timer);
      showError(data.error);
    }
  }, POLLING_INTERVAL);
}

import { phylotree, phylotree_node } from 'phylotree';

/** 解析Newick为phylotree实例 */
export function parseNewick(newickStr: string): typeof phylotree.prototype {
  return new phylotree(newickStr.trim());
}

/** 计算树统计信息 */
export function computeTreeStatistics(tree: typeof phylotree.prototype): TreeStatistics {
  let sequenceCount = 0, totalBranches = 0, totalBranchLength = 0, treeHeight = 0;
  const bootstrapValues: number[] = [];

  tree.traverse_and_compute((node: phylotree_node) => {
    const bl = node.attribute || 0;
    totalBranchLength += bl;
    totalBranches++;
    if (!node.children || node.children.length === 0) sequenceCount++;
    if (node.confidence !== undefined) bootstrapValues.push(node.confidence);
    
    const rootToTip = computeRootToTipDistance(node);
    if (rootToTip > treeHeight) treeHeight = rootToTip;
  });

  return {
    sequenceCount,
    treeHeight: Math.round(treeHeight * 10000) / 10000,
    totalBranches,
    avgBranchLength: Math.round((totalBranchLength / totalBranches) * 10000) / 10000,
    minBootstrap: bootstrapValues.length ? Math.min(...bootstrapValues) : 0,
    maxBootstrap: bootstrapValues.length ? Math.max(...bootstrapValues) : 0,
    avgBootstrap: bootstrapValues.length 
      ? Math.round((bootstrapValues.reduce((a, b) => a + b, 0) / bootstrapValues.length) * 100) / 100
      : 0
  };
}

/** 生成渲染选项(支持暗黑模式) */
export function createRenderOptions(vizConfig: VizConfig, isDark: boolean) {
  const colors = isDark ? {
    nodeFill: '#63e2b7', nodeStroke: '#63e2b7', branchStroke: '#a0a0a0',
    text: '#e0e0e0', bootstrap: '#f0a020'
  } : {
    nodeFill: '#18a058', nodeStroke: '#18a058', branchStroke: '#555555',
    text: '#333333', bootstrap: '#f0a020'
  };

  return {
    zoom: true, brush: true, collapsible: true, selectable: true, reroot: true,
    'align-tips': vizConfig.alignTips, 'show-scale': vizConfig.showScaleBar,
    'color-fill': colors.nodeFill, 'color-stroke': colors.branchStroke,
    'color-text': colors.text, 'color-bootstrap': colors.bootstrap,
    'font-size': vizConfig.fontSize, 'branch-width': vizConfig.branchWidth,
    layout: vizConfig.layout === 'rectangular' ? 'linear' 
          : vizConfig.layout === 'radial' ? 'radial' : 'circular',
  };
}

/** phylotree.js Vue封装类 */
export class PhyloTreeRenderer {
  private tree: any = null;
  private container: HTMLElement | null = null;
  private options: Record<string, unknown> = {};

  init(container: HTMLElement, options: Record<string, unknown> = {}) {
    this.container = container;
    this.options = options;
    this.clear();
  }

  render(newickStr: string, options: Record<string, unknown> = {}) {
    if (!this.container) return;
    this.clear();
    this.options = { ...this.options, ...options };
    this.tree = new phylotree(newickStr.trim());
    this.tree.render({ container: this.container, ...this.options });
  }

  updateOptions(options: Record<string, unknown>) {
    if (!this.tree || !this.container) return;
    this.options = { ...this.options, ...options };
    this.tree.render({ container: this.container, ...this.options });
  }

  highlightNode(nodeId: string) {
    if (!this.tree) return;
    let target: any = null;
    this.tree.traverse_and_compute((node: any) => { if (node.name === nodeId) target = node; });
    if (target) this.tree.modify_selection([target]);
  }

  exportSVG(): string {
    const svg = this.container?.querySelector('svg');
    return svg ? new XMLSerializer().serializeToString(svg) : '';
  }

  exportNewick(): string {
    return this.tree ? this.tree.get_newick() : '';
  }

  clear() { if (this.container) this.container.innerHTML = ''; }
  destroy() { this.clear(); this.tree = null; this.container = null; }
}
