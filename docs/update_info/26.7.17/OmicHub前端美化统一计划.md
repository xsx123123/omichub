# OmicHub 前端美化与统一计划

> 目标：**精致 · 统一 · 简约**。先修一致性（P0），再做精致化（P1），最后埋彩蛋（P2）。
> 适用范围：React + Arco Design + Plotly 技术栈下的全部页面（登录页 / 首页 / 仪表板 / 分析中心 / 实验室知识库 / 数据管理 / 数据库 / 生信工具箱）。

## 二、统一设计规范（Design Tokens）

先建立全局 Token，所有页面改造时只准引用 Token，禁止写死色值。

### 2.1 色彩

| Token | 值 | 用途 |
|-------|-----|------|
| `--brand-primary` | `#4C6FFF` | 主按钮、链接、激活态 |
| `--brand-gradient` | `linear-gradient(135deg, #4C6FFF 0%, #8B5CF6 100%)` | Hero 横幅、公告条、Logo 强调 |
| `--bg-page` | `#F5F6FA` | 页面底色 |
| `--bg-card` | `#FFFFFF` | 卡片 |
| `--text-primary` | `#1D2129` | 标题 |
| `--text-secondary` | `#4E5969` | 正文 |
| `--text-tertiary` | `#86909C` | 辅助说明 |
| `--success` `#00B42A` / `--warning` `#FF7D00` / `--danger` `#F53F3F` | — | 仅用于状态语义，不做装饰 |

**图标配色规则（语义化，结束随机取色）：**
- 分析流程类 → 品牌蓝紫渐变
- 数据 / 存储类 → 青蓝（`#0FC6C2`）
- 可视化类 → 紫（`#8B5CF6`）
- 系统 / 设置类 → 中性灰蓝（`#5B8FF9`）
- 状态类（成功 / 警告 / 失败）→ 仅用状态色

### 2.2 形状与层次

| Token | 值 |
|-------|-----|
| `--radius-card` | `12px` |
| `--radius-button` | `8px` |
| `--shadow-card` | `0 1px 2px rgba(29,33,41,.04), 0 4px 16px rgba(29,33,41,.06)` |
| `--shadow-card-hover` | `0 4px 8px rgba(76,111,255,.08), 0 12px 32px rgba(76,111,255,.12)` |
| 卡片间距 | `16px`（网格 gutter） |
| 页面内边距 | `24px` |

卡片统一为：**纯白底 + 12px 圆角 + 轻阴影，取消所有顶部渐变描边**（数据库物种卡的彩色顶条与推荐流程卡的蓝顶条全部移除，用左侧 4px 品牌色竖条或图标即可区分层级）。

### 2.3 组件规格

- **PageHeader（全站唯一规格）**：浅色方案——标题 24px/600 + 灰色副标题 14px + 右侧操作区；**不**再用深色渐变 Hero 大卡（数据库页的 Hero 降级为标准 PageHeader，把渐变留给首页星尘工作站横幅——全站只允许首页这一个"舞台"）。
- **公告条（全站唯一皮肤）**：品牌蓝紫渐变底 + 白字 + 白色描边按钮 + 可关闭；首页与仪表板共用同一组件。
- **Tag**：默认中性浅灰底（`#F2F3F5` + `#4E5969`），仅"版本号"用品牌蓝浅底；取消按流程随意换色。
- **按钮层级**：页面主操作 = 实底品牌蓝；次操作 = 描边；危险操作 = 红色描边；渐变底上的按钮 = 白底白字描边（仅此一种）。
- **文案语言**：全站中文为主语言；专有名词（SRA / GEO / BLAST / FASTQ）保留英文；按钮与空状态提示一律中文化（"清理缓存"、"管理存储"、"该文件夹暂无数据集"）。
- **滚动条**：全局改为 6px 细滚动条，hover 时显现（`::-webkit-scrollbar` 覆盖）。

## 三、趣味元素方案（彩蛋层）

> 原则：**点缀而非喧闹**。彩蛋只在"等待、空白、节日"三个时刻出现，不干扰分析工作流。

1. **星尘猫吉祥物（主彩蛋）**：把登录页的"猫踩地球"注册为平台吉祥物，出现在——
   - 空状态（"这里空空如也，喵～ 上传第一个数据集吧"）
   - 404 页（猫在星空里迷路）
   - 长时间任务等待页（猫蹲坐看流星，附一句随机俏皮话）
2. **节气问候**：首页问候语从"夜深了，JIAN"升级为「时辰 + 节气」双彩蛋——按当前日期显示节气（如"大暑将至"）并配一句应景古诗，按时段显示"清晨 / 午后 / 夜深"；数据用本地 JSON 节气表，不依赖外部 API。
3. **任务完成撒花**：分析任务成功时右上角 Toast 变成迷你星尘粒子爆发动画 + 文案"又一颗星尘归位 ✨"。
4. **节日皮肤开关**：系统设置里加"节日彩蛋"开关（默认开），中秋时登录页月亮变大、春节时星尘变红色微粒子；用户可一键关闭回归极简。
5. **加载动画**：全局 Loading 从默认转圈改为 DNA 双螺旋脉冲或小行星环绕动画（CSS 实现，<10KB）。
6. **隐藏彩蛋**：连点 5 次侧边栏 Logo，触发 3 秒全屏流星雨（仅前端，不发请求）。

## 四、实施路线图

### P0 — 一致性修复（半天 ~ 1 天）
1. 建立 `theme/tokens.css`（或 CSS-in-JS 变量层），全站替换硬编码色值
2. 公告条合并为单一组件 `AnnouncementBar`
3. PageHeader 统一为浅色规格，数据库页 Hero 降级
4. 数据管理页文案中文化
5. 移除卡片顶部渐变描边，统一圆角阴影
6. 登录按钮改品牌蓝实底

### P1 — 精致化（1 ~ 2 天）
1. 登录页卡片改毛玻璃（`backdrop-filter: blur(20px)` + 半透明白底），引言只保留底部一处
2. 空状态组件库 `EmptyState`（星尘猫插画 + 文案 + CTA），替换仪表板零值平线与数据管理空文件夹
3. 图表空数据时不渲染坐标轴，直接显示 EmptyState
4. 全站细滚动条
5. 图标配色按语义规则收敛
6. 微交互：卡片 hover 上浮 2px + 阴影加深，数字滚动动画（count-up）

### P2 — 彩蛋层（1 天）
1. 星尘猫空状态 / 404 / 等待页
2. 节气 + 时辰问候
3. 任务完成星尘爆发 Toast
4. DNA 加载动画
5. 节日皮肤开关 + 流星雨彩蛋

4. 每轮完成后让 CC 输出一份 `CHANGELOG-UI.md`，记录改动文件清单，方便你 review。
