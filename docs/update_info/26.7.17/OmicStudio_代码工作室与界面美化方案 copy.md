## 二、代码工作室（VS Code 式编辑器面板）

### 2.1 三种视图模式

中栏顶部增加分段切换控件，三种模式覆盖不同工作节奏：

```
┌──────────────────────────────────────────────┐
│ [ 💬 对话 ] [ ◧ 分屏 ] [ 📝 代码 ]            │
└──────────────────────────────────────────────┘
```

| 模式 | 布局 | 适用场景 |
| --- | --- | --- |
| **对话模式**（默认） | 现状：对话流占满中栏 | 描述任务、看 AI 干活、快速追问 |
| **分屏模式** | 中栏纵向切左右：左对话流（40%）+ 右编辑器（60%），分隔条可拖拽 | **核心模式**：边看 AI 解释边改代码，改完即跑 |
| **代码模式** | 编辑器占满中栏，对话收为右下角悬浮按钮（带未读角标），点击上滑为抽屉 | 深度手改脚本、纯自研时刻 |

模式状态记在会话上，刷新后恢复。

### 2.2 编辑器规格（Monaco）

```
┌────────────────────────────────────────────────────────┐
│ [pca_analysis.py ✕] [volcano_v2.py ● ✕]      [+ 终端]  │ ← Tab 栏
│ scripts › pca_analysis.py                    ▶ 运行 ⏹  │ ← 面包屑 + 运行控制
├────────────────────────────────────────────────────────┤
│  1  import pandas as pd                                │
│  2  import matplotlib.pyplot as plt                    │
│  3  ...                                                │
├────────────────────────────────────────────────────────┤
│ 终端 ▾  python scripts/pca_analysis.py                 │
│ ✓ Exit code: 0 · 产物: output/pca_plots.png (+2)       │
├────────────────────────────────────────────────────────┤
│ 🟢 沙盒运行中 · python 3.12 · 行 6, 列 2 · 7.9 KB · UTF-8│ ← 状态栏
└────────────────────────────────────────────────────────┘
```

- **Tab 行为对齐 VS Code**：文件树**单击** = 预览 Tab（标题斜体，再开新文件会替换）；**双击**或编辑后 = 固定 Tab；未保存显示 ● 圆点。
- **语言识别**：按扩展名（py/r/sh/R/md/json/yaml/csv 只读表格），代码用浅色主题（GitHub Light 风），与对话流代码卡片同款。
- **快捷键**：`Ctrl/Cmd+S` 保存；`Ctrl/Cmd+Enter` 运行当前文件；`Shift+Enter` 运行选中片段（右键菜单也有「运行选中代码」）。
- **保存即同步**：保存走 `workspace_write`，AI 侧上下文即刻可见（工作区文件是单一事实源，本来就该如此）。

### 2.3 与对话流的双向联动（灵魂）

| 方向 | 触发 | 行为 |
| --- | --- | --- |
| 对话 → 编辑器 | 代码卡片「在编辑器打开」按钮 | 切到分屏模式并激活对应 Tab |
| 对话 → 编辑器 | AI 调用 `workspace_write` / `workspace_edit` | Tab 上显示变更圆点；若开启「跟随 AI」开关（默认开）则自动激活该文件并**内联 diff 装饰**（新增绿底/删除红划线，逐 hunk 提供 接受/拒绝） |
| 编辑器 → 对话 | 用户保存文件 | 对话流插入一条轻量系统消息「✏️ 你修改了 volcano_v2.py」，AI 上下文同步更新，不产生气泡打扰 |
| 编辑器 → 对话 | 编辑器内运行 | 输出同时出现在编辑器底部终端 panel **和**对话流执行卡片中（同一份数据两处渲染） |
| 冲突 | 用户正在编辑的文件被 AI 修改 | 编辑器顶部黄色提示条：「AI 刚刚修改了此文件 · [查看 diff] [接受] [保留我的版本]」，绝不静默覆盖 |

**大改 vs 小改**：AI 改动 <20 行用内联装饰；≥20 行或重写整个文件时，自动开一个 Monaco DiffEditor 对比 Tab（左旧右新），底部操作条「全部接受 / 全部拒绝 / 复制新文件」。

### 2.4 运行控制与终端

- 运行按钮按文件类型派生命令：`python -u {file}` / `Rscript {file}` / `bash {file}`；CSV 等不可运行文件按钮置灰。
- 运行中：▶ 变 ⏹（停止 = 向沙盒发 SIGINT/SIGKILL）；面包屑右侧出现跑马灯小 spinner。
- 终端 panel：可拖拽高度、可折叠；深色（见 §3 色板），流式输出，超 10KB 折叠为「已输出 N 行 · 展开」；结束显示 exit code 徽章（0 绿 / 非 0 红）+ 产物清单 chips（点击直跳产物面板）。
- 底部状态栏：沙盒状态灯、镜像 python 版本、光标行列、文件大小、编码——VS Code 用户秒懂，零学习成本。

### 2.5 文件树升级（配合编辑器）

- 文件类型彩色图标（py 蓝黄、csv 绿、png 紫、md 灰蓝……轻量仿 material icons）；
- 右键菜单：打开 / 重命名 / 删除 / 下载 / 在对话中引用；
- 单击预览、双击固定的 VS Code 行为；
- 树顶部小工具条：新建文件、新建文件夹、刷新、显示隐藏文件开关、「从数据管理引入」挪到这里（图标按钮 + tooltip），底部大按钮撤掉。

## 三、界面美化规范

### 3.1 设计基调

> 「深夜实验室里的一盏星空灯」——浅色干净基底 + 平台紫主色 + 克制的星空彩蛋。工作台是干活的地方，**精致感靠层级、留白和微交互，不靠装饰堆砌**。

### 3.2 色板（工作台专属，汇入平台 CSS 变量）

```css
--studio-bg:        #f7f7fb;   /* 页面底：极浅灰紫 */
--studio-card:      #ffffff;   /* 卡片 */
--studio-border:    #e8e8f2;   /* 1px 细边框 */
--studio-primary:   #6c5ce7;   /* 主紫：按钮、链接、勾选 */
--studio-primary-soft: #f0edff;/* 主紫浅底：用户气泡、选中态 */
--studio-text:      #2b2b3d;   /* 正文 */
--studio-text-sub:  #8a8aa3;   /* 次要文字 */
--studio-terminal:  #1b1b2e;   /* 终端底：深紫灰（非纯黑） */
--studio-ok:        #22c55e;   /* 成功/exit 0 */
--studio-warn:      #f59e0b;
--studio-err:       #ef4444;
```

阴影统一：`0 1px 2px rgba(60,60,100,.04), 0 4px 16px rgba(60,60,100,.06)`；圆角：卡片 12px、按钮 8px、芯片 999px。

### 3.3 组件逐项优化

**① 顶栏**：毛玻璃（`backdrop-filter: blur(12px)` + 半透明白底）；左侧返回箭头 + 会话标题（16px/600）+ 智能体徽章（小胶囊，紫底白字）+ 模型名（12px 灰字）；右侧图标统一 18px 灰色、hover 变紫 + tooltip 文字，顺序固定：分享 / 导出 / 重连沙盒 / 右栏开关。

**② 用户消息**：深紫实底气泡 → **浅紫底（--studio-primary-soft）+ 深紫文字（#3d3666）右对齐卡片**，无头像或弱化头像；hover 浮现操作（重发/编辑/复制/删除），不再常驻一排。

**③ AI 消息**：白卡片 + 细边框 + 统一阴影；智能体小圆头像带 2px 紫色微光晕；消息内标题层级收紧（h3 不超过 15px）。

**④ 终端/执行卡片**：底色改 `--studio-terminal` 深紫灰，圆角 12px；顶部加 macOS 三色点装饰 + 语言标签（PYTHON/BASH）+ exit code 徽章（绿✓/红✗）；「运行/复制」改 ghost 小按钮，hover 白边。整体从「一块黑砖头」变成「嵌在卡片里的精致终端」。

**⑤ 对话内代码卡片**：浅色 GitHub 风代码主题；顶部文件路径面包屑（`scripts › pca_analysis.py`）+ 右侧「在编辑器打开 / 重跑 / 复制」三个小图标；与编辑器同款字体字号，两处观感一致。

**⑥ 右栏重构**：三块改**手风琴**（产物默认展开，待办/沙盒可折叠）：
- 产物卡片：缩略图放大（图片 56px 圆角缩略图 / 文件类型图标），操作图标收到 hover 浮层，全部带 tooltip（预览/下载/插入对话/登记报告）；新产物到达时卡片淡入 + 顶部 toast「✨ 新产物已就位」。
- 待办计划：checkbox 用主紫；完成态 = 紫勾 + 文字划线变淡紫灰；**空状态画小插画**（望远镜/星星 SVG）+ 文案「任务启航后，计划将在此列队 ⭐」。
- 沙盒状态：状态灯脉冲动画 + CPU/内存细进度条 + 工作区路径等宽字体。

**⑦ 左栏**：会话列表项加智能体头像小圆点；文件树见 §2.5；整体 hover 态用浅紫底。

**⑧ 输入框**：**撤掉橙边**——默认 1px `--studio-border`，focus 时紫边 + 淡紫光晕；圆角 16px；工具图标统一 18px 灰 + tooltip（灵感/附件/联网/终端）；「深度思考」改紫色描边小胶囊，开启时实心紫；底部彩蛋文案保留，改淡紫色 ✨ 前缀：「✨ 以上星尘由硅基网络演算，请以碳基智慧感知」。

**⑨ 微交互与彩蛋**（每处只做一次，克制）：
- 沙盒启动：状态灯黄色脉冲 + toast「沙盒点火中…🚀」；
- 产物登记成功：产物卡片上一个小星星飞入动画；
- 长时间运行：输入框 placeholder 轮换（「正在跑第 3 步，去倒杯咖啡？」）；
- 会话空状态：淡色星空渐变底 + 一句「把工作台交给星光，把问题交给我们」。

## 六、一句话总结

把代码卡片升级成真正的「编辑器」，让对话流和代码之间可以互相跳转、互相看见对方的修改——这就是 VS Code 回环的完全体；再配上一套克制的紫色系美化，工作台就从「能用」变成「好用且好看」。
