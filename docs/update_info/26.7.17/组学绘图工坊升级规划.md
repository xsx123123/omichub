# 组学绘图工坊 v2 升级规划

> 目标：把绘图工坊从「Mock 演示页」升级为「上传数据 → 格式检测 → 列映射 → 交互绘图 → 高清导出」的完整工具，交互水准对齐火山图页面，配色体系统一继承基因表达矩阵 Explorer。

---

## 一、现状诊断

| 维度 | 现状 | 差距 |
|---|---|---|
| 数据上传 | 仅一个 CSV/TSV 上传按钮，未选择时用 Mock 数据 | 无格式说明、无校验、无列映射 |
| 图表类型 | 柱状 / 折线 / 散点 / 热图 / 箱线 5 种，均无参数面板 | 无分组、无统计、无拟合 |
| 配色 | 仅 Viridis 一个色板 | 未复用 Explorer 的 Friendly / Seaside / Apple / IBM / Candy |
| 导出 | 无 | 火山图已有 PNG(多 DPI)/SVG/重置视图/全屏，应全套继承 |
| 结果面板 | 无 | 火山图有统计卡片 + Top 列表，柱状图/箱线图同样需要统计结果面板 |

**核心原则：火山图页面已有的交互范式（数据上传与列映射 → 阈值与颜色 → 坐标轴与标题 → 统计侧栏 → 导出栏）就是绘图工坊的模板，不做第二套设计。**

## 二、总体架构

### 2.1 统一工作流（所有图表共用）

```
上传 CSV/TSV
   ↓
解析（PapaParse，自动嗅探分隔符 , / \t / ;）
   ↓
格式检测（每种图一个 Schema Validator，输出错误报告）
   ↓
列映射 UI（下拉选择：分组列 / 数值列 / X 列 / Y 列 / ID 列）
   ↓
参数面板（颜色 / 统计 / 坐标轴 / 标题）
   ↓
Plotly 渲染（统一 chart theme）
   ↓
导出：PNG(300/600/1000 DPI) · SVG · 统计结果 CSV
```

### 2.2 配色继承方案

从 Explorer 抽出一个公共模块 `src/components/charts/palettes.ts`（或已有的等价位置），两处共用：

```ts
// 离散色板（分组着色：柱状图/箱线图/折线图/散点图分组）
export const DISCRETE_PALETTES = {
  Friendly: [...],   // 继承 Explorer 现有定义
  Seaside:  [...],
  Apple:    [...],
  IBM:      [...],
  Candy:    [...],
};

// 连续色板（热图 / 相关性矩阵用）
export const CONTINUOUS_PALETTES = {
  Viridis: [...],
  RdBu:    [...],   // 表达量热图经典红蓝（发散色，center=0）
  Blues:   [...],
  Plasma:  [...],
};
```

- 离散图默认 **Friendly**（与 Explorer 默认一致，保证跨工具视觉统一）
- 热图默认 **RdBu 发散色板**（z-score 标准化后居中于 0 是组学惯例），Viridis 作为备选
- Explorer 后续加色板只改这一个文件

## 三、五大图表规格

每种图给出：数据格式示例、必需/可选列、校验规则、核心参数、统计功能。

### 3.1 热图（Heatmap）

**数据格式：宽表矩阵**，第一列为 ID（基因/特征名），其余每列为一个样本。

```csv
gene,Sample_A1,Sample_A2,Sample_B1,Sample_B2
TP53,8.21,7.95,5.12,5.44
BRCA1,4.10,4.33,6.78,6.91
EGFR,9.02,8.87,3.21,3.05
```

| 项目 | 规则 |
|---|---|
| 必需列 | 1 个 ID 列 + ≥2 个数值列 |
| 上限 | 行 ≤ 5000、列 ≤ 200（超出提示先做特征筛选，防浏览器卡死） |
| 校验 | ① 非 ID 列必须全部可转数值，否则报「第 X 列第 Y 行含非数值 "abc"」；② 允许空值，提供处理选项：删除该行 / 填 0 / 填行均值；③ ID 重复时警告并自动去重（保留首行） |
| 参数 | 标准化：行 Z-score（默认）/ 列 Z-score / log2(x+1) / 无；聚类：行 / 列 / 双向 / 无；距离：欧氏 / 皮尔逊相关；色板：连续色板；显示行列名开关、单元格数值开关 |
| 加分项 | 支持上传第二个「样本分组注释文件」（两列：sample, group），在热图顶部渲染颜色注释条 |

### 3.2 柱状图（分组 + 显著性分析）⭐ 核心需求

**数据格式：长表**，一列分组、一列数值，每行一个重复。

```csv
group,value
Control,78.2
Control,81.5
Control,76.9
Treatment,92.4
Treatment,95.1
Treatment,89.8
```

| 项目 | 规则 |
|---|---|
| 必需列 | 1 个分组列 + 1 个数值列 |
| 校验 | ① 组数 ∈ [2, 12]；② 每组重复数 ≥ 3 才允许做显著性检验，< 3 时画柱但提示「重复不足，无法检验」；③ 数值列含非数值 → 定位到行号报错 |
| 统计 | 两组：Student t / Welch t / Mann-Whitney U（用户选）；≥3 组：one-way ANOVA + Tukey HSD 事后检验，或 Kruskal-Wallis + Dunn（非参数）；多重校正：Bonferroni / FDR-BH |
| 标注方式 | 两两比较：星号括号（* <0.05, ** <0.01, *** <0.001, ns）；多组：紧凑字母标记 CLD（a / ab / b），默认字母法——组学文章主流 |
| 参数 | 误差棒：SD / SEM / 95%CI；叠加散点 jitter 开关；柱宽、组内顺序拖拽排序 |
| 结果侧栏 | 对齐火山图右侧面板：检验方法、每组 mean±SD、两两比较 p 值表（可导出 CSV） |

### 3.3 散点图（拟合 + 趋势线）

**数据格式：两列数值**，可选第三列分组。

```csv
expression,trait
8.21,72.5
7.95,69.1
5.12,45.3
```

| 项目 | 规则 |
|---|---|
| 必需列 | X 数值列 + Y 数值列；可选 group 列（分组着色 + 分组拟合） |
| 校验 | ① X/Y 必须数值，≥ 5 个有效点才可拟合；② X 方差为 0 → 提示无法回归；③ 缺失行自动剔除并计数提示 |
| 拟合 | 线性回归（默认）/ 二次、三次多项式 / LOESS 平滑；95% 置信带开关 |
| 标注 | 图上显示：回归方程、R²、Pearson r 与 p 值（可切换 Spearman ρ）；有分组时每组独立标注 |
| 参数 | 点大小 / 透明度（继承 Explorer 的 PCA 点大小、透明度交互）；坐标轴范围自动/手动；轴标题自定义 |
| 场景 | 这个图直接服务你的 GPSE 工作——预测值 vs 表型观测值散点 + 拟合线就是论文标准图 |

### 3.4 箱线图（Boxplot）

**数据格式：与柱状图相同的长表**（group + value），可与柱状图共用同一份上传数据和 Validator。

| 项目 | 规则 |
|---|---|
| 必需列 | 1 个分组列 + 1 个数值列 |
| 校验 | 同柱状图（组数 [2, 12]，每组 ≥ 3 时可做显著性） |
| 参数 | 显示全部散点（jitter）开关；离群点显示开关；notch（缺口箱线）开关；组顺序自定义 |
| 统计 | 与柱状图共用同一套检验引擎，显著性字母/星号标在每组箱线上方 |
| 加分项 | 一键切换「箱线 / 小提琴 / 箱线+小提琴叠加」三种形态（小提琴见 4.1） |

### 3.5 折线图（Line）

**数据格式两种任选**，上传后自动识别：

```csv
# 宽表：第一列 X（时间点/连续变量），其余每列一条线
time,Line_A,Line_B
0,10.2,12.1
24,25.4,18.3
48,44.1,30.2

# 长表：X + 数值 + 分组列
time,value,line
0,10.2,Line_A
0,12.1,Line_B
```

| 项目 | 规则 |
|---|---|
| 必需列 | X 列 + ≥1 个数值列（宽表）或 X + value + group（长表） |
| 校验 | ① X 列重复值 → 提示「检测到重复 X，将按组聚合为均值±SD 误差带」；② 数值校验同上 |
| 参数 | 误差带（mean ± SD/SEM 半透明带）开关；点标记开关；平滑（线性 / spline）；配色继承离散色板 |
| 场景 | 时间序列表达量、不同基因型生长曲线 |

## 四、建议新增的图表（按优先级）

### P0（与现有需求同期做，边际成本低）
| 图表 | 理由 | 数据格式 |
|---|---|---|
| **小提琴图** | 与箱线图共用 Validator 和统计引擎，仅渲染层不同 | 同箱线图长表 |
| **相关性热图** | 复用热图组件，输入任意数值矩阵自动算 Pearson/Spearman 相关矩阵再渲染，表型-表型、表达-表达相关性高频需求 | 同热图宽表 |
| **直方图/密度图** | 数据分布速查，支持分组叠加；校验最简单（1 个数值列） | 1 数值列 + 可选分组列 |

### P1（第二批）
| 图表 | 理由 | 数据格式 |
|---|---|---|
| **PCA 图** | Explorer 已有 PCA 计算逻辑，搬过来做成独立工具；上传表达矩阵直接出 PCA + 分组着色 + 置信椭圆 | 同热图宽表 + 可选分组注释文件 |
| **MA 图** | 与火山图共用 DEG 数据格式和列映射，改个坐标轴计算（A=mean, M=log2FC） | 同火山图（gene, log2FC, baseMean/padj） |
| **气泡图** | 富集分析结果标配（x=GeneRatio, y=通路, size=count, color=padj） | term, GeneRatio, padj, count 四列 |
| **误差棒点图** | 摘要数据（只有 mean 和 SD、没有原始重复）也能画，与柱状图互补 | group, mean, sd (或 sem) 三列 |

### P2（第三批，锦上添花）
- **棒棒糖图**（group + value，替代柱状图的极简风）
- **雷达图**（多指标样本画像，行=指标列=样本）
- **生存曲线 KM**（time, event, group 三列；如果平台未来接医学/动物数据再上，纯植物场景可砍）
- **曼哈顿图**已在你 OmicHub 规划里作为独立模块，不进工坊，避免重复建设

## 五、格式说明与检测（用户体验设计）

### 5.1 格式说明入口（每个图表页三件套）

1. **「格式要求」折叠卡片**：放在上传按钮正下方，内含——必需列说明表格 + 复制即用的格式示例 + 常见错误提醒
2. **「下载示例数据」按钮**：每种图附一个 `example_heatmap.csv` 等模板文件，用户下载改数即可用（对齐火山图右上角「示例数据」按钮的交互）
3. **上传后即时校验**：不点「生成图表」不校验是反模式，应改为文件一落盘就解析校验

### 5.2 校验反馈规范

```
✅ 检测通过：已识别 3 组 × 4 重复，共 12 行（Control / Treatment_A / Treatment_B）
⚠️  警告：第 17 行 value 为空，已自动剔除（共剔除 2 行）
❌ 错误：第 9 行 "value" 列含非数值 "NA."，请修正后重新上传
❌ 错误：每组至少需要 3 个重复才能进行显著性检验（Treatment 组仅 2 个）
```

- 错误必须**定位到行号 + 列名 + 具体值**，禁止「文件格式不正确」这种废话提示
- 校验结果用 Arco 的 Alert 组件分级展示（success / warning / error）
- 检测通过时顺带展示数据摘要（组数、重复数、行数），让用户确认「程序理解的数据 = 我的数据」

## 六、统计引擎实现方案

| 检验 | 实现位置 | 说明 |
|---|---|---|
| t / Welch t / Mann-Whitney U | 前端（jstat） | 成熟稳定，无后端依赖 |
| Pearson / Spearman 相关 | 前端（jstat / simple-statistics） | 简单 |
| 线性 / 多项式回归、LOESS | 前端（regression 库 / d3） | d3-regression 体积小 |
| one-way ANOVA | 前端（jstat） | 可实现 |
| **Tukey HSD / Dunn / CLD 字母标记** | **建议后端 Python**（scipy + scikit-posthocs + statsmodels） | studentized range 分布前端实现易错，后端一个 `/api/stats/posthoc` 接口返回两两 p 值矩阵 + 字母分组，前端只负责标注 |

> 若短期不想加后端依赖，P0 阶段可先只做：两组比较（t/U 检验 + 星号）+ ANOVA 总 p 值；Tukey 字母标记留到 P1。

### Prompt 2（S2 核心四图）

```
基于已完成的 ChartWorkbench 框架，实现四个图表定义（ChartDefinition）：

1. 热图 HeatmapDefinition：宽表矩阵格式（首列 ID，其余为样本数值列，行≤5000 列≤200）。参数：标准化（行Z-score默认/列Z-score/log2(x+1)/无）、聚类（行/列/双向/无，欧氏或皮尔逊距离，层次聚类自行实现或用 ml-hclust）、连续色板（默认 RdBu 且值域以 0 为中心对称）、行列名显示开关。校验：非 ID 列必须全数值，空值提供「删除该行/填0/填行均值」三选一处置，ID 重复警告并保留首行。
2. 分组柱状图 BarDefinition：长表（group + value 两列）。两组时用 jstat 做 Student t / Welch t / Mann-Whitney U（用户下拉选），图上画星号括号（* <0.05, ** <0.01, *** <0.001, ns）；≥3 组先画柱并显示 one-way ANOVA 总 p 值，事后检验留接口待后端。误差棒 SD/SEM/95%CI 可选，jitter 散点叠加开关。右侧面板展示每组 mean±SD 和检验 p 值表（对齐火山图右侧统计面板样式），可导出 CSV。组数校验 [2,12]，每组≥3 重复才启用检验。
3. 散点拟合 ScatterDefinition：X、Y 两个数值列 + 可选 group 列。线性回归默认（切换二次/三次多项式/LOESS），95% 置信带开关，图上标注回归方程、R²、Pearson r 与 p 值（可切 Spearman）；有分组时每组独立拟合独立标注。点大小/透明度参数继承 Explorer 的交互样式。≥5 个有效点才允许拟合。
4. 箱线图 BoxDefinition：与柱状图共用长表格式和统计检验，显著性标在每盒上方；参数：jitter 散点开关、离群点开关、notch 开关、组顺序自定义。

四个图都默认 Friendly 离散色板（热图默认 RdBu），每个页面配 example_*.csv 示例数据文件和「格式要求」卡片。折线图沿用现有实现但接入新框架，支持宽表/长表自动识别、重复 X 聚合为 mean±SD 误差带。
```
