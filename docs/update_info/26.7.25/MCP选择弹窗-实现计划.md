# 任务：MCP 选择弹窗（在文件/Agent/Skill 弹窗完成后实施）

## 前置与约束

- 依赖已完成的"触发符弹窗与输入框一体化"容器结构，MCP 弹窗复用同一套 `.composer` 容器、定位方式（left:-1px; right:-1px; bottom:calc(100%-1px)）、背景/描边/圆角变量与出现动画，禁止新造一套浮层样式。
- 在现有输入框工具栏基础上新增一个 MCP 图标按钮（hammer/工具类图标），不改动其他按钮。

## 入口与状态反馈

- 点击工具栏 MCP 按钮弹出 MCP 选择弹窗；Esc 或点击空白处关闭。
- 按钮需反映当前状态：非"自动"默认态时图标高亮；手动模式下在图标右上角显示已额外启用的 MCP 数量角标（如 +2）。

## 弹窗结构（参考 Codex/Kimi CLI 的 MCP 面板）

- 模式区（单选，每行：图标 + 名称 + 右侧描述）：
  1. 禁用 —— 不使用 MCP 工具；
  2. 自动 —— AI 自动发现和使用工具（默认选中）；
  3. 手动 —— 选择特定的 MCP 服务器。
- 选择"手动"时展开 MCP 服务器列表，分两组：
  - **Agent 默认**：当前 agent 自带 MCP，固定勾选、置灰不可取消，行尾带"默认"徽标；
  - **可添加**：其他已配置的 MCP 服务器，checkbox 多选，行尾带"MCP"徽标，每行显示名称 + 一句话描述。
- 列表底部固定入口："＋ 添加自定义 MCP..."，点击展开二级表单：名称、连接方式（stdio 命令 / SSE URL / Streamable HTTP URL）、确认按钮；保存前做连通性校验，失败在表单内给出具体错误信息，成功则加入"可添加"组并默认勾选。
- 底部快捷键栏沿用统一 spec：Esc 关闭、↑↓ 选择、Enter 确认。

## 数据流（必须遵守）

- 选择结果存于当前会话状态（mcpMode: 'off'|'auto'|'manual'，extraMcpServers: 手动模式下额外勾选的 MCP 列表）；
- 发送消息时随请求体传给后端；后端**在 agent 默认 MCP 列表基础上合并**用户额外选择，按名称去重，禁止用用户选择覆盖默认列表；
- 会话级生效：切换会话恢复该会话上次的选择，新会话默认"自动"。

## 验收 Checklist

- [ ] 工具栏出现 MCP 按钮，点击弹出弹窗，弹窗与输入框为一体化容器（同宽、0间距、共享边框）
- [ ] 禁用/自动/手动三档可切换，默认"自动"
- [ ] 手动模式下 Agent 默认 MCP 置灰锁定且带"默认"徽标，可添加组可多选
- [ ] "添加自定义 MCP"可录入 stdio/SSE/HTTP 三种方式，连通性校验失败有具体报错
- [ ] 手动模式下按钮图标显示额外启用数量角标
- [ ] 发送请求的请求体中包含 mcpMode 与 extraMcpServers，后端与默认 MCP 合并去重
- [ ] 切换会话后 MCP 选择随会话恢复
