# 工具页面视觉优化实现计划

> 适用对象：编码 Agent（kimi code / Claude Code / CODEX 等）
> 平台：生信科研工具平台（顶部导航：控制台 / 分析中心 / 实验室知识库 / 关于）
> 涉及页面：组学绘图工坊、Web 基因组浏览器、云端沙盒终端

---

## 一、背景与目标

平台内多个工具页的页头与顶部导航的间距不统一：「FASTQ 极速质控」「序列检索 BLAST」页头与导航之间有充足留白，观感舒适；而「组学绘图工坊」「Web 基因组浏览器」「云端沙盒终端」三个页面的页头紧贴导航栏，视觉压抑且风格不一致。此外「Web 基因组浏览器」的顶部工具栏存在控件拥挤、文字截断、按钮风格混搭、坐标重复显示等问题。

**目标：**

1. 全平台工具页的页头间距统一，以「FASTQ 极速质控 / 序列检索 BLAST」为标杆；
2. 重构「Web 基因组浏览器」顶部工具栏，消除截断、拥挤与风格混搭；
3. 修复参考基因组 / 坐标区域的重复显示与样式问题；
4. 全程只改样式与布局结构，不改任何功能逻辑。

**参考标杆截图依据：**

| 页面 | 页头与导航间距 | 状态 |
|---|---|---|
| FASTQ 极速质控 | 充足（标杆） | ✅ 无需改动 |
| 序列检索 BLAST | 充足（标杆） | ✅ 无需改动 |
| 组学绘图工坊 | 过近，紧贴导航 | ❌ 待修复 |
| Web 基因组浏览器 | 过近，紧贴导航 | ❌ 待修复 |
| 云端沙盒终端 | 过近，紧贴导航 | ❌ 待修复 |

## 二、问题清单（逐条含 spec）

### 问题 1：页头与顶部导航间距不一致（3 个页面）

- **现状**：组学绘图工坊、Web 基因组浏览器、云端沙盒终端的页头（返回按钮 + 标题 + 副标题）上边缘几乎贴着顶部导航栏下边缘，间距约 8~16px；而 FASTQ 极速质控 / 序列检索 BLAST 约为 40px 以上。
- **根因方向**：各页面容器的 `padding-top` 各自硬编码，未走统一规范。
- **修改 spec**：
  - 统一页面内容容器（或 PageHeader 组件）的上间距：`padding-top: 40px`（桌面端 ≥1024px）、`24px`（移动端）；
  - 页头区块与下方内容区间距统一：`margin-bottom: 24px`；
  - 优先做法：若项目已有 PageHeader / 页面容器组件，只改这一处；若没有，抽取公共样式类（如 `.tool-page-header`）在三个页面复用，**禁止在三个页面各写一套近似但不相同的数值**；
  - 副标题样式顺带对齐标杆页：14px、`#6b7280`、与标题间距 8px。

### 问题 2：Web 基因组浏览器顶部工具栏样式混乱

- **现状**：标题（带 DNA emoji）、「参考基因组」标签、基因组下拉框、坐标输入框、「跳转」「上传文件」「我的文件」按钮全部挤在同一行；「跳转」是实心蓝按钮，「上传文件 / 我的文件」是白底灰边按钮，风格混搭；右上角还有被裁切的绿色徽标；副标题「基于 JBrowse 2 · 支持 BAM / BigWig / VCF / GFF3 流式浏览」孤零零挂在第二行。
- **修改 spec**：
  - **拆成两层结构**：
    - 第一层为标准页头：返回按钮 + 标题「Web 基因组浏览器」（**去掉 DNA emoji**，或替换为与其他工具页一致的线性图标）+ 副标题，样式与其他工具页页头完全一致；
    - 第二层为独立工具栏卡片：白底、12px 圆角、1px `#e5e7eb` 描边、内边距 `12px 16px`，与平台卡片体系一致。
  - **工具栏内部布局**：左组 = 参考基因组选择器 + 坐标输入框 + 跳转按钮；右组 = 上传文件、我的文件（`margin-left: auto` 右对齐）；控件统一高度 36px、圆角 8px、间距 12px。
  - **按钮风格统一**：「跳转」为唯一主按钮（主题蓝实心，如 `#4a6cf7` 或项目现有主题色变量）；「上传文件」「我的文件」统一为 outline 样式（白底、1px `#d1d5db` 边框、`#374151` 文字），hover 态边框加深为 `#9ca3af`。
  - **修复裁切**：右上角被裁切的绿色徽标（连接/状态指示）移入工具栏卡片内部右侧，或修复其定位，确保完整显示且不被导航栏遮挡。

### 问题 3：参考基因组选择器与坐标区域样式差、坐标重复显示

- **现状**：
  - 基因组下拉框文字被截断为「人类 (GRCh38/hg38) · Ho…」，关键信息（拉丁学名）丢失；
  - 坐标输入框带 🧭 emoji 前缀，与平台其他线性图标风格不符；
  - 坐标 `chr1:1000000-2000000` 在界面上**重复出现两次**；
  - 坐标无千分位，长数字难读。
- **修改 spec**：
  - **选择器**：下拉框最小宽度 240px；选中态显示「人类 (GRCh38/hg38)」单行，拉丁学名 *Homo sapiens* 以 12px 灰色（`#9ca3af`）副行或 tooltip 呈现；下拉选项内采用两行排版——第一行 14px `#111827`「人类 (GRCh38/hg38)」，第二行 12px 斜体 `#6b7280`「Homo sapiens」；任何情况下不截断中文名与版本号。
  - **坐标输入框**：去掉 🧭 emoji，改为无前缀或线性定位图标（与平台图标体系一致）；宽度 220px；placeholder 为格式示例 `chr1:1,000,000-2,000,000`；显示值加千分位（输入解析仍兼容无千分位与空格）。
  - **坐标去重**：排查重复来源（输入框值与旁边的状态文本重复渲染，或跳转后 location 被写入两处）。当前位置只保留**一处**主展示（工具栏坐标输入框内）；如确需在视图区显示当前范围，放在基因组浏览器视图内的状态条，样式为 12px 等宽字体、`#6b7280`，不与工具栏重复。

### 问题 4：云端沙盒终端页头间距

- **现状**：与问题 1 相同，页头「云端沙盒终端 + 选择预装工具链的镜像，启动一个隔离、用完即毁的沙盒终端」紧贴顶部导航。
- **修改 spec**：由问题 1 的统一修复覆盖，本页面不单独写样式；修复后核对页头下方「选择分析环境」卡片与页头的间距与标杆页一致（24px）。

## 四、全局约束（三个阶段通用）

- 这是对**已有页面的优化**，不是重新设计；禁止推倒重写任何页面。
- 不改路由、不改功能逻辑、不动导航栏本身、不动无关页面（尤其两个标杆页）。
- 所有样式数值优先引用项目现有的主题变量 / 设计 token，不要新建一套近似但不相同的色值与间距。
- 与平台整体风格保持一致（卡片体系、主题蓝、字体层级与其他工具页对齐）。
- 交互动效（hover、focus、下拉展开）时长 200~300ms，不添加循环动效。
- 移动端不出现横向滚动。

## 六、代码勘察发现（2026-07-25，实现前必读）

> 本节为动手前的实际代码勘察结论。所有路径相对 `frontend/`。技术栈：Vue 3 + TS + Naive UI + Tailwind + Vite，页面样式以 `<style scoped>` 为主。

### 6.1 页面与路由映射（`src/router/index.ts`）

| 计划页面 | 组件文件 | 路由 | 备注 |
|---|---|---|---|
| FASTQ 极速质控（标杆） | `views/BioTools/FastqQCView.vue` | `/tools/fastq-qc` | 不要改 |
| 序列检索 BLAST（标杆） | `views/BioTools/BlastSearchView.vue` | `/tools/blast` | 不要改 |
| 组学绘图工坊（待修复） | `views/BioTools/PlotWorkshopView.vue` | `/tools/plot` | |
| Web 基因组浏览器（待修复） | `views/BioTools/JBrowseViewer.vue` | `/tools/jbrowse` | `meta.fullscreen: true` |
| 云端沙盒终端（待修复） | `views/BioTools/TerminalView.vue` | `/tools/terminal`（`/sandbox` 重定向至此） | |

### 6.2 外层布局机制（`src/layouts/DefaultLayout.vue` 的 `contentStyle` computed）

- `route.meta.fullscreen`（即 JBrowse）：`padding: 0; display:flex; flex-direction:column; flex:1; min-height:0`
- 工具箱区域（`/tools` 及 `/tools/*`，但排除 `/tools/jbrowse`）：外层 `padding: 0`，注释明确写「由各工具页面根容器自行控制 16px 内边距」
- 其他页面：`padding: 24px`

**结论**：工具页的「页头与导航间距」完全由各页面根容器自己的 `padding-top` 决定，外层不给任何 padding。

### 6.3 共享组件 `src/components/PageHeader.vue`

五个页面均使用它（JBrowse / Plot / Terminal / FASTQ / BLAST 都已 `import PageHeader`）。
- `.page-header { margin-bottom: 24px }` —— 「页头与下方内容间距 24px」**已天然满足**
- 标题 `h1`：24px / 600；副标题 `p`：14px / `var(--text-secondary)` / `margin: 6px 0 0`（与标题间距当前 **6px**，计划要求 8px，如需严格对齐可微调）
- 提供 `#leading`、`#actions` 两个插槽。**注意：JBrowse 目前把所有控件塞进了 `#actions`，这正是拥挤的根源**

### 6.4 三个待修复页面的根因（padding-top 不一致）

| 页面 | 根容器样式 | 顶部间距 | 问题 |
|---|---|---|---|
| FastqQC（标杆） | `.fastq-page { min-height:100%; padding:16px }`（移动 ≤620px → `padding:12px`） | 桌面 16px / 移动 12px | 基准 |
| Blast（标杆） | `.blast-page { min-height:100%; padding:16px }` | 16px | 基准 |

- 会话模式：`v-if="session"` 渲染 `.terminal-header.session-header`（终端工具条，`padding:8px 16px`，应贴顶）
- 选择模式：`v-else` 渲染 `PageHeader`
- 选择模式内容在 `.terminal-selector { max-width:1240px; margin:0 auto; padding:20px }` 内
- **不能**简单给 `.terminal-page` 加 `padding-top`，否则会话模式工具条被顶下去。需只作用于选择模式（如给 PageHeader 包一层带 top padding 的容器，或加仅选择模式生效的 class）

### 6.6 可用设计 Token（`src/styles/tokens.css` + `global.css`）

### 6.7 ⚠️ 计划与代码的关键矛盾（实现前需拍板）

计划背景称标杆页「约 40px 以上」，但**实测代码标杆页根容器 `padding: 16px`（top 16px）**，并非 40px。计划同时给出两条规则：
- 「以标杆页实测一致为准」（tiebreaker）
- 目标参考值「桌面 40px / 移动 24px」

二者冲突。验收项「五个页面间距肉眼一致」+「不改动标杆页」→ 逻辑上只有让三个页面 = 标杆页的 **16px**（桌面）/ **12px**（移动）才能同时满足。计划作者称赞的「充足留白」其实就是 16px 的 FASTQ。

**建议（待确认）**：以「与标杆页像素一致」为准，三个页面 `padding-top` 对齐 16px（桌面）/ 12px（移动），引用 `--space-lg` / 移动用 `--space-md`。若用户确实想要更大的 40px 呼吸感，则必须同步调整标杆页（与「不改标杆页」冲突），需用户明确取舍。

### 6.8 建议实现方案（供接手工具参考）

1. **阶段一（统一间距）**：
   - PlotWorkshop：`.workshop-page` padding `0 24px 24px` → `16px 24px 24px`（移动 `0 12px 16px` → `12px 12px 16px`）
   - JBrowse：给 `.jbrowse-page` 顶部加 16px（注意它是 fullscreen flex 列，header+toolbar 整体下移，browser-view 因 `flex:1` 自动收缩，符合预期）
   - Terminal：仅对选择模式的 PageHeader 加顶部间距（包容器或专属 class），勿影响会话模式 `.terminal-header`
   - 三处统一引用 `--space-lg`(16px)/移动 `--space-md`(12px)，不写三套近似值
   - 如需 8px 标题副标题间距，微调 `PageHeader.vue` 的 `.page-header-copy p { margin-top }`（6px→8px），全站生效、含标杆页，属组件级统一改而非单页 hack
2. **阶段二（JBrowse 工具栏重构）**：把 `#actions` 内控件移出，PageHeader 只留标题（去 🧬）+ 副标题；下方新增独立 `.toolbar-card`（`--neutral-card` 底、`--radius-card`、1px `--neutral-border`、`padding:12px 16px`），左组=基因组选择器+坐标输入+跳转（唯一主按钮），右组=上传/我的文件（outline，`margin-left:auto`）；控件高 36px、圆角 `--radius-button`、间距 `--space-md`；窄屏 `flex-wrap`
