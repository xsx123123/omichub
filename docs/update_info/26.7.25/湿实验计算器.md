## 参考标杆（组学绘图工坊）的可复用特征

- 卡片式分区：白色卡片 + 圆角（约 12px）+ 轻阴影 + 1px 浅灰描边，卡片之间间距统一
- 状态徽标：绿色 pill（如"6 条有效数据"）、绿色校验通过提示块（浅绿底 + 对勾图标）
- 内容区有明确的层次：主结果突出、辅助说明弱化、底部有摘要信息区
- 控件风格统一：下拉框/输入框带浅灰边框，折叠面板（分区标题 + chevron 图标）

## 需要修改的问题（逐条执行）

1. 【页面空洞、大片留白】：当前内容卡片只占据页面上半部，下半屏是完全空白的灰色背景。
   将内容区扩展为分区卡片结构：每个 Tab 至少包含「输入区卡片」「结果区卡片」「计算原理/
   说明卡片」三个独立卡片（说明从结果面板底部拆出为独立卡片，带图标标题如"计算原理"），
   垂直方向自然填充页面；卡片样式直接复用绘图工坊的卡片规范（白底、12px 圆角、
   阴影与 1px #e5e7eb 描边）。

2. 【结果区缺乏视觉重点】：当前结果只是浅灰面板里的一行文字。
   - 结果卡片顶部或左侧加主题色高亮条（4px，使用项目主题蓝，如 #4a6cf7 或现有
     CSS 变量）；
   - 结果关键数字（如"10 μL""18.02 mg""25.25 nM"）放大到 28~32px、字重 700、
     主题蓝色；等式其余文字 16px、#374151；
   - 辅助说明（如"母液占终体积 10%"）14px、#6b7280，与主结果拉开间距。

3. 【缺少状态反馈】：参考绘图工坊的绿色徽标体系：
   - 计算成功时，结果卡片右上角显示绿色 pill 徽标（如"计算完成"，浅绿底 #ecfdf5、
     文字 #059669、12px、圆角 999px）；
   - 输入不合法或无法计算时（如 C2 > C1），显示红色/琥珀色提示块（浅红底 + 图标），
     替代现在把提示混在说明文字里的做法；
   - qPCR Tab 粘贴数据并识别成功后，显示"已识别 N 行、M 个分组"的绿色校验提示块，
     样式与绘图工坊"检测通过"提示一致。

4. 【空结果区无引导】：qPCR Tab 右侧结果区在粘贴数据前是一大片空白浅灰面板。
   为空态加占位样式：居中显示淡色图标（如试管/图表线性图标，#d1d5db）+
   一行引导文字（"粘贴 Ct 数据后自动计算 2^-ΔΔCt"，14px、#9ca3af），
   参考绘图工坊说明卡片的排版气质。

5. 【输入控件质感弱】：输入框和下拉框边框过淡、与背景几乎融为一体。
   统一控件规范：默认边框 1px #d1d5db、圆角 8px、高度 36~40px；
   focus 态边框变主题蓝 + 外发光 box-shadow: 0 0 0 3px rgba(74,108,247,0.15)；
   hover 态边框加深为 #9ca3af。单位下拉框与输入框之间的间距统一为 8px。

6. 【隐私横幅过重】：顶部"纯本地运算，数据不离开浏览器"横幅目前是一整条浅紫横带，
   视觉过重。收窄为内联提示条：高度约 36px、浅蓝灰底（如 #f0f4ff）、13px 文字、
   图标与文字垂直居中，或改为标题右侧的小徽标形式。

7. 【风格全局对齐】：四个 Tab 的标题层级、卡片间距、主题色、字体族全部与绘图工坊
   页面对齐（直接使用绘图工坊已有的样式变量/类名，不新建一套近似但不相同的样式）。

## 全局约束

- 整体风格必须与组学绘图工坊及平台首页保持一致（同一套卡片、配色、字体体系）。
