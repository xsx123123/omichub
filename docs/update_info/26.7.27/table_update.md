## 需要修改的问题（逐条执行）

1. 【卡片选中高亮与表格底色冲突】当前卡片选中态使用浅蓝紫色底（约 #eef0fb 系），
   而卡片内表格区域又铺了一层半透明白底，两种颜色叠在一起显得脏、边界不清。
   修改方案：
   - 卡片选中态改为「左侧 3~4px 主题色竖条 + 1px 高亮描边（主题色 40% 透明度）
     + 极浅色底（不浅于 #f7f8ff）」，不再使用明显的蓝紫实底；
   - 表格容器背景改为不透明实色 #ffffff，表头行背景 #f7f8fa，与卡片底色形成
     清晰的明暗分层，不允许半透明叠加；
   - 未选中态卡片保持现有中性底色不变，只改选中态。

2. 【进度列 "100%" 折行】进度列中进度条 + 百分比文字排不下，"100" 和 "%" 被挤成
   两行。修改方案：
   - 进度单元格改为 flex 布局且不换行：进度条 flex: 1、min-width: 60px；
     百分比文字 white-space: nowrap，固定宽度 44px 右对齐，
     加 font-variant-numeric: tabular-nums 保证数字宽度稳定；
   - 「进度」列设置 min-width: 160px（表格列宽分配时优先保证该列），
     确保 0%~100% 任意值都单行显示。

3. 【列对齐统一为居中】该表各列数据短且同构，统一居中后表头与数据上下对齐更整齐。
   修改方案：
   - 表格所有列（表头 th + 单元格 td）统一 text-align: center，包括
     所属用户、任务名称、分析流程、提交时间、状态、进度、操作；
   - 操作列图标按钮组用 flex justify-content: center + gap: 12px 居中排列；
   - 若表格组件库支持 column 级 align 属性，优先用组件配置而非全局 CSS 覆盖。
