# OmicHub 实验室知识库：目录折叠条修复与星空品牌化方案

> 对象：实验室知识库页面左侧目录侧边栏。
> 两件事：① 修复折叠态底部出现"可拖动水平滚动条"的逻辑 bug；
> ② 将折叠态空白窄条改造为品牌化"星空条"，呼应平台星尘/宇宙主题
> （首页 "We are made of star-stuff" / FROM STARDUST, TO DISCOVERY）。

---

## 一、现状与问题诊断

### 1.1 Bug：折叠态底部的"进度条"实为水平滚动条

- **现象**：目录折叠后，侧边栏收缩为约 60px 窄条，底部残留一根可拖动的
  水平滚动条（截图特写确认）。
- **根因**：折叠后目录树内容**只是被隐藏、并未卸载**，其固有宽度远超 60px，
  容器 `overflow-x` 暴露出水平滚动条。这根条滚动的是一个用户看不见的
  内容区——纯逻辑错误。
- **正确行为**：
  - 折叠态：目录树不渲染（`v-if` 卸载），容器 `overflow: hidden`；
  - 展开态：容器 `overflow-x: hidden`，目录节点文本超长时 `ellipsis` 截断
    （tooltip 显示全名）——**任何状态下侧边栏都不应出现水平滚动条**。

### 1.2 折叠态全空白

折叠后窄条只有顶部一个展开按钮，其余全白，视觉上像"没加载完的残件"。
知识库恰好是平台星尘主题最强的页面（首页横幅卡尔·萨根引言），折叠条
适合做成品牌元素而非留白。

## 二、折叠条设计方案（星空主题）

### 2.1 结构 Spec

```text
┌────┐
│  > │  展开按钮（顶部）：圆形 rgba(255,255,255,0.1) 底，hover 0.2
│    │
│ ✦  │  星空层：8~12 颗 CSS 星点，直径 1~2px，白/浅蓝 #cfe0ff，
│ 实 │  基础透明度 0.2~0.6 随机分布，6~10s 缓慢闪烁（仅 opacity）
│ 验 │
│ 室✦│  竖排标题"实验室知识库"：
│ 知 │  writing-mode: vertical-rl，12px，
│ 识 │  rgba(255,255,255,0.55)，letter-spacing 4px，垂直居中
│ 库 │
│ ✦  │  底色：深蓝垂直渐变 #0d1b3e → #16264f，
│    │  右侧 1px rgba(255,255,255,0.08) 分隔线
│  + │  底部快捷：新建文档（白 70%，hover 全亮 + tooltip）
│  ⏳ │  底部快捷：待审核（同上）
└────┘
   宽 56px，全高；展开/折叠宽度过渡 250ms ease-in-out
```

### 2.2 设计决策说明

| 决策 | 理由 |
|---|---|
| **深蓝底 + 白星点**（而非浅底蓝星） | 星空在浅底上无质感；56px 深色窄条仅占页面 <3% 面积，不破坏整体浅色体系，反而成为品牌锚点，与首页星尘文案呼应 |
| **只做慢闪烁**（无流星/漂浮粒子） | 知识库是阅读场景，动效必须让位于正文；透明度 ≤0.6、周期 6~10s、只动 opacity，视觉存在但不抢戏 |
| **hover 轻微提亮**（1.2 倍，300ms） | 给窄条一点"活"的反馈，引导用户发现它可交互 |
| **底部快捷按钮** | 折叠态不只是装饰：新建文档、待审核两个高频动作保留入口，行为与展开态一致 |
| **`prefers-reduced-motion` 静止** | 平台统一无障碍规范，星点在系统减弱动效下完全不闪 |

### 2.3 浅色备选方案

若坚持全浅色体系：底色 `#f5f7fb`，星点用主题蓝（如 #4f8ef7），竖排标题
`rgba(0,0,0,0.45)`，分隔线 `rgba(0,0,0,0.06)`，其余 spec 不变。
（推荐深蓝版，品牌感差异明显。）

```text
你是一名资深前端工程师。项目为 OmicHub 多助手平台，前端 Vue3 + Naive UI。

任务：修复折叠态滚动条 bug，并将折叠态窄条改造为品牌化星空条。先阅读现有

## 一、滚动条逻辑修复（bug，最高优先级）

1. 折叠态：目录树不渲染（v-if 卸载而非仅隐藏），折叠容器 overflow: hidden。
2. 展开态：容器 overflow-x: hidden，目录树节点文本超长时 ellipsis 截断
   （tooltip 显示全名）——任何状态下侧边栏不得出现水平滚动条。
3. 检查根因并说明：当前水平滚动条是哪个容器、哪条 CSS 导致的，
   修复后验证展开/折叠/窗口缩放三种场景均无横向滚动条。

## 二、折叠条品牌化（星空主题）

折叠态窄条按以下 spec 实现，全部用 CSS，不引入新依赖：

1. 尺寸与底色：宽 56px，全高，深蓝垂直渐变（#0d1b3e → #16264f），
   右侧 1px rgba(255,255,255,0.08) 分隔线；展开/折叠宽度过渡
   250ms ease-in-out。
2. 顶部：展开按钮（chevron-right），圆形 rgba(255,255,255,0.1) 底，
   hover 提亮至 0.2。
3. 中部：竖排标题"实验室知识库"，writing-mode: vertical-rl，12px，
   rgba(255,255,255,0.55)，letter-spacing 4px，垂直居中。
4. 星空层：纯 CSS 星点（多层 radial-gradient 背景或 box-shadow 多点
   实现均可），8~12 颗星，直径 1~2px，白色/浅蓝（#cfe0ff），
   基础透明度 0.2~0.6 随机分布；闪烁动画 6~10s ease-in-out infinite
   alternate，每颗星 animation-delay 错开；只动 opacity，不用位移动画。
5. 交互：hover 折叠条时星点整体亮度提升至 1.2 倍（过渡 300ms）；
   prefers-reduced-motion 时星点静止（无闪烁动画）。
6. 底部快捷按钮：新建文档（+）、待审核（对应图标），白色 70% 透明度，
   24px，纵向排列，hover 全亮并显示 tooltip；点击行为与展开态对应
   按钮一致。
```

## 四、实施与风险

- **工作量**：纯前端、零依赖，约半天（bug 修复 1h + 星空条 3h）。
- **风险 1：星空层性能**。CSS 多层 radial-gradient 重绘成本极低，但禁止改成
  canvas/JS 粒子方案（过度工程且引入主线程开销）；星点数上限 12 颗。
- **风险 2：闪烁动画干扰阅读**。若用户反馈抢戏，第一调节手段是把透明度
  上限从 0.6 降到 0.4、周期从 6~10s 放缓到 10~14s，而不是删效果。
- **风险 3：v-if 卸载目录树导致折叠/展开时树状态丢失**。展开态的节点
  展开/选中状态应存于组件外层 state（不随树卸载重置），验收时覆盖
  "展开若干节点 → 折叠 → 再展开，状态保持"。
- **回归**：目录树选中、新建文档、待审核入口、文档编辑/删除按钮零改动。
