# 星尘AI Hero 样式优化 — 实现计划（Part 1）

> 目标：让「星尘 AI」助手 hero 区域与 OmicHub 星尘工作站平台主视觉保持一致，消除"浅紫消息气泡"与"深蓝→紫渐变宇宙风"之间的风格割裂。
> 性质：**对已有页面的视觉优化，不是重新设计**。不改路由、不改功能逻辑、不动四个快捷建议卡片的业务行为。

---

## 一、背景与目标

### 现状（截图 1）
- hero 为一张浅薰衣草紫（约 `#EEF0FC`）圆角卡片，左侧紫色圆形内嵌指南针 emoji 🧭，标题"星尘 AI"+ 一行说明文字，右上角灰色 × 关闭按钮。
- 下方四张白色快捷建议卡片，左侧浅色方块图标（浅蓝/浅紫/浅青/浅绿底 + ✦）。
- 整体气质：轻盈、气泡化，像一张普通通知卡片。

### 平台主视觉基准（截图 2、3）
- **主 hero**：深蓝 → 紫渐变横幅（约 `#1E6FFF → #8B5CF6`），白色文字层级（问候小字 → 大字标题 → 说明文字），白底实心主按钮 + 毛玻璃描边次按钮，右侧细白色圆环装饰。
- **通知横幅**：紫色渐变条 + 白底胶囊按钮。
- **引用卡**：浅紫白渐变底 + 蓝色大写英文小标题（`FROM STARDUST, TO DISCOVERY`，加宽字距）+ 深色衬线斜体大引文 + 蓝色装饰点。
- 平台标志性元素：宇宙/星尘意象、蓝紫渐变、英文 kicker + 大标题的两级层级、玻璃质感按钮、圆环/星点装饰。

### 目标
星尘AI hero 复用上述视觉语言：渐变底、白色文字层级、英文 kicker、玻璃质感关闭按钮、星尘装饰，四张建议卡片做配套统一（图标渐变、hover 反馈）。

## 二、问题清单与修改 spec（逐条转数值）

| # | 现状问题 | 修改 spec | 预期效果 |
|---|---|---|---|
| 1 | hero 背景是浅薰衣草紫 `#EEF0FC` 单色，和平台深蓝紫渐变 hero 完全两种气质 | 改为与平台主 hero 同向渐变：`linear-gradient(120deg, #1E6FFF 0%, #4F6DF5 45%, #8B5CF6 100%)；圆角 16px；padding 48px 56px` | 与首页 hero 一眼同源 |
| 2 | 深底后文字配色缺失规则 | 标题纯白 `#FFFFFF` 700 32px；说明文字 `rgba(255,255,255,0.85)` 15px/1.7；对比度满足 WCAG AA | 深底文字清晰可读 |
| 3 | 紫色圆 + 🧭 emoji 头像过于工具感，与"星尘/宇宙"品牌不符 | 替换为平台 logo（同首页 hero 的星尘 logo）或 56px 圆形玻璃容器：`background: rgba(255,255,255,0.15); backdrop-filter: blur(8px); border: 1px solid rgba(255,255,255,0.35)`，内置 ✦/logo | 品牌感统一，去掉 emoji 感 |
| 4 | 缺少平台的"英文 kicker + 大标题"两级层级 | 标题上方加 kicker：`STARDUST AI ASSISTANT`，大写、12px、字距 0.15em、`rgba(255,255,255,0.75)`；下方依次为 32px 标题 + 说明行 | 与引用卡/hero 的排版节奏一致 |
| 5 | 右上角 × 是灰色裸图标，在深渐变上会看不清 | 改为 32px 玻璃圆形按钮：`background: rgba(255,255,255,0.12); border: 1px solid rgba(255,255,255,0.25)`，白色 16px 图标，hover 背景升至 0.22，过渡 200ms | 深底上可见、有反馈 |
| 6 | hero 内无任何装饰，平台感缺失 | 右侧加 2~3 个细白色圆环（border 1~2px `rgba(255,255,255,0.18)`，直径 120~240px，部分出血裁切 `overflow: hidden`），再撒 4~6 个 3~5px 白色星点（opacity 0.4~0.9），**静态、无循环动画** | 呼应"星尘"意象，不抢内容 |
| 7 | 四张建议卡的浅色方块图标偏灰淡，与新 hero 衔接生硬 | 图标容器改为 40px 渐变方块（蓝 `#6366F1→#3B82F6`、紫 `#8B5CF6→#6366F1`、青 `#06B6D4→#3B82F6`、绿 `#14B8A6→#06B6D4`），图标白色；卡片 `border: 1px solid #E8EAF6`，hover `translateY(-2px)` + `box-shadow: 0 8px 24px rgba(30,111,255,0.10)`，过渡 200~300ms | 与新 hero 色系衔接，有 hover 反馈 |
| 8 | 建议卡标题/副标题灰度层级与平台不统一 | 标题 `#1A1D33` 600 15px；副标题 `#8A8FA3` 13px（与平台正文灰一致） | 灰阶体系统一 |

### 全局约束
- 渐变方向、蓝紫色值与平台首页 hero 同源（若项目已有主题变量，直接复用变量，不要新写硬编码色值）。
- 装饰元素全部静态，禁止循环漂浮动画；交互动效 200~300ms。
- 保持响应式：移动端 padding 降为 24px、标题 24px，装饰圆环缩小或隐藏，不出现横向滚动。
- 不改路由、不改卡片点击逻辑、不引入新依赖。

## 三、实施阶段

### 阶段 1：hero 卡片重构（问题 1~6）
只动 hero 容器、标题区、关闭按钮与装饰层。完成后验收：与首页 hero 并排放截图，渐变方向与色感一致；文字在渐变上清晰可读；× 按钮 hover 有反馈。

### 阶段 2：四张建议卡配套统一（问题 7~8）
只动建议卡片的图标容器、边框、hover 与文字灰阶。完成后验收：四图标渐变与 hero 同色系；hover 有上浮+阴影；标题/副标题灰阶与平台其他页面一致。

### 回退方案
两个阶段的改动相互独立，均限定在 hero 组件与建议卡组件的样式层。若阶段 1 效果不满意，单独回退该组件样式文件即可，阶段 2 不受影响。

```text

任务：在现有「星尘 AI」助手 hero 组件基础上做视觉优化，使其与平台首页（OmicHub 星尘工作站）

无关组件，禁止引入新依赖（确有必要先说明理由）。

## 需要修改的问题（逐条执行）

### 阶段 1：hero 卡片
1. [背景割裂]：当前 hero 是浅薰衣草紫单色卡片，与平台深蓝→紫渐变 hero 风格不符。
   将背景改为 linear-gradient(120deg, #1E6FFF 0%, #4F6DF5 45%, #8B5CF6 100%)，
   圆角 16px，padding 48px 56px；若首页 hero 已有主题变量/渐变定义，直接复用。
2. [文字配色]：深底后文字需统一为——标题纯白 700 32px，说明文字
   rgba(255,255,255,0.85) 15px/1.7，对比度不低于 WCAG AA（4.5:1）。
3. [emoji 头像]：紫色圆形 + 🧭 emoji 头像与平台品牌不符。替换为平台 logo
   （同首页 hero），或 56px 玻璃圆形容器：background: rgba(255,255,255,0.15);
   backdrop-filter: blur(8px); border: 1px solid rgba(255,255,255,0.35)。
4. [缺层级]：标题上方增加英文 kicker "STARDUST AI ASSISTANT"：大写、12px、
   字距 0.15em、rgba(255,255,255,0.75)，与平台引用卡的 kicker 风格一致。
5. [关闭按钮]：右上角灰色 × 在深渐变上不可读。改为 32px 玻璃圆形按钮：
   background: rgba(255,255,255,0.12); border: 1px solid rgba(255,255,255,0.25);
   白色 16px 图标，hover 背景升至 0.22，过渡 200ms。
6. [缺装饰]：hero 右侧加 2~3 个细白色圆环（border 1~2px rgba(255,255,255,0.18)，
   直径 120~240px，容器 overflow: hidden 允许部分出血），再撒 4~6 个 3~5px 白色
   星点（opacity 0.4~0.9）。全部静态，禁止循环动画。

### 阶段 2：四张建议卡
7. [图标灰淡]：四张建议卡的浅色方块图标改为 40px 渐变方块（蓝 #6366F1→#3B82F6、
   紫 #8B5CF6→#6366F1、青 #06B6D4→#3B82F6、绿 #14B8A6→#06B6D4），图标白色；
   卡片 border: 1px solid #E8EAF6，hover 时 translateY(-2px) +
   box-shadow: 0 8px 24px rgba(30,111,255,0.10)，过渡 200~300ms。
8. [灰阶不统一]：建议卡标题 #1A1D33 600 15px，副标题 #8A8FA3 13px。

## 全局约束

- 整体风格必须与平台首页 hero、紫色通知横幅、引用卡保持一致（蓝紫渐变 + 星尘装饰 +
  英文 kicker 层级）。
- 保持响应式：移动端 padding 24px、标题 24px、装饰圆环缩小或隐藏，不出现横向滚动。
- 所有交互动效 200~300ms，无循环动效。
- 不改卡片点击逻辑与文案内容（文案如需微调先征求确认）。

## 验收标准（逐条自检）

- [ ] 与首页 hero 并排截图对比：渐变方向、色感、文字层级一致
- [ ] 关闭按钮在渐变底上清晰可读，hover 有反馈
- [ ] 四张卡片点击行为与改前完全一致
- [ ] 桌面/移动两种宽度下无布局破损、无横向滚动

完成后简述：每个问题对应的修改文件与关键属性改动。
```
