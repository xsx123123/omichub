# OmicHub 首页快捷入口与分析流程卡片优化 — 实现计划

> 版本：v1.0　日期：2026-07-29
> 范围：平台首页（快捷入口卡片区 + "三步开始你的分析"区块）
> 性质：**对已有首页的局部修改，不是重新设计**。不改路由、不改卡片跳转逻辑、不动"系统管理"横幅。
> 本文件覆盖第 1 轮需求：AI 助手卡片品牌化为星尘AI + 分析流程区新增 Agent 路径卡片。

---

## 一、背景与目标

### 现状（首页截图）
- 「快捷入口」5 张卡片：RNA-seq 分析 / ATAC-seq 分析 / 数据管理 / **AI 助手（智能分析与问答）** / 任务中心，第二行第三格空缺。
- 「三步开始你的分析」3 张步骤卡：① 上传样本数据 ② 选择分析流程 ③ 查看分析结果。
- 底部「系统管理」横幅（本次不动）。

### 问题
1. **品牌口径断裂**：助手在对话页、hero 均已品牌化「星尘AI」，首页卡片仍写通用名「AI 助手」，副标题"智能分析与问答"也未体现生信 Agent 能力。
2. **Agent 能力在首页零露出**：平台已具备生信 Agent（结果解读、全流程自动化），但"三步开始你的分析"只呈现手动路径，新用户感知不到 Agent 能直接走完全流程。

### 目标
- 卡片文案/图标与「星尘AI」品牌对齐。
- 分析流程区形成"手动三步 + Agent 全流程"双路径结构，Agent 卡片高亮但风格仍在平台视觉体系内。

## 二、问题清单与修改 spec

| # | 位置 | 现状问题 | 修改 spec | 预期效果 |
|---|---|---|---|---|
| 1 | 快捷入口·AI 助手卡 | 标题"AI 助手"与全站品牌"星尘AI"不一致 | 标题改为「星尘AI」；跳转目标不变（仍进助手对话页） | 品牌口径全站统一 |
| 2 | 快捷入口·AI 助手卡 | 副标题"智能分析与问答"空泛 | 改为「对话式生信分析与结果解读」 | 一眼看懂能干什么 |
| 3 | 快捷入口·AI 助手卡 | 绿色聊天气泡图标与星尘/宇宙视觉体系不符 | 图标换 ✦（星芒/星尘意象），图标容器底色与其他卡片的浅色方块体系保持一致（建议浅紫 `#F3F0FF` 底 + `#8B5CF6` 图标） | 视觉归入品牌体系 |
| 4 | 三步分析区块 | Agent 能力无露出 | 区块标题「三步开始你的分析」保持不变；在 3 张步骤卡下方新增一张**通栏高亮卡**「交给星尘AI」：主文案"一句话描述需求，星尘AI 自动完成数据上传、流程执行与结果解读"，右侧 CTA 按钮「开始对话」（跳助手对话页，与快捷入口卡同一目标） | 手动/自动双路径，逻辑不打架 |
| 5 | 三步分析区块 | 新增卡片若用普通白卡，会被步骤卡淹没 | 高亮卡用平台主 hero 同源的蓝紫渐变：`linear-gradient(120deg, #1E6FFF 0%, #4F6DF5 45%, #8B5CF6 100%)`，白字（标题 700 16~18px、说明 `rgba(255,255,255,0.85)` 13px），CTA 为白底实心按钮（文字 `#1E6FFF`）；左侧加 ✦ 图标（玻璃容器：`background: rgba(255,255,255,0.15); border: 1px solid rgba(255,255,255,0.35)`）；**静态、无循环动画** | 与星尘AI hero 视觉同源，有重点但不突兀 |

### 被否决的备选（记录用）
- ❌ 把"智能解读结果"加为线性第 4 步：与"Agent 走完全流程"定位矛盾（既是终点又是全程替代），且四张步骤卡会把区块挤成 2×2 或一行四列，破坏现有三列节奏。Agent 是**替代路径**不是流程环节，故做成并列高亮卡。

### 全局约束
- 在现有首页组件基础上修改，**先读现有代码再改**，禁止推倒重写；不改路由、不改其他卡片跳转。
- 若项目已有主题变量（蓝紫渐变、文字灰阶），直接复用变量，不要新写硬编码色值。
- 文案保持平台现有语气（简洁、陈述句），不引入 emoji。

## 三、分阶段实现

**单阶段交付**（改动小、无耦合，一次完成）：

1. 快捷入口「AI 助手」卡：标题/副标题/图标三处替换（spec #1~3）。
2. 三步分析区块：新增通栏高亮卡「交给星尘AI」（spec #4~5）。
3. 响应式核对：桌面端通栏卡与上方三列等宽对齐；移动端纵向堆叠，CTA 不折行。

### 本阶段提示词（可直接粘贴给编码 Agent）

```text
在现有 OmicHub 平台首页基础上做两处局部修改，不是重新设计。先读首页相关组件代码再动手，不改路由、不改任何卡片的跳转目标、不动"系统管理"横幅和其余四张快捷入口卡片。若项目已有主题变量（蓝紫渐变、文字灰阶），复用变量，不要新写硬编码色值。

【改动 1：快捷入口"AI 助手"卡片品牌化为星尘AI】
1. 卡片标题"AI 助手"改为「星尘AI」。
2. 副标题"智能分析与问答"改为「对话式生信分析与结果解读」。
3. 图标从绿色聊天气泡改为 ✦（星芒/星尘意象），图标容器保持与其他快捷卡片一致的浅色方块体系：浅紫底 #F3F0FF + 图标色 #8B5CF6（若现有卡片图标容器用的是 CSS 变量/统一类名，沿用同一套，仅换图标与配色）。
4. 点击跳转目标保持不变（助手对话页）。

【改动 2：分析流程区新增 Agent 路径高亮卡】
1. "三步开始你的分析"区块标题和三张步骤卡保持原样不动。
2. 在三张步骤卡下方新增一张通栏高亮卡片「交给星尘AI」：
   - 主标题：交给星尘AI（700，16~18px，纯白 #FFFFFF）
   - 说明文字：一句话描述需求，星尘AI 自动完成数据上传、流程执行与结果解读（13px，rgba(255,255,255,0.85)，对比度满足 WCAG AA）
   - 左侧图标：✦ 放在圆形玻璃容器内（background: rgba(255,255,255,0.15); border: 1px solid rgba(255,255,255,0.35); backdrop-filter: blur(8px)）
   - 右侧 CTA 按钮「开始对话」：白底实心、文字色 #1E6FFF，点击跳转助手对话页（与快捷入口星尘AI卡同一目标）
   - 卡片背景：与平台主 hero 同源渐变 linear-gradient(120deg, #1E6FFF 0%, #4F6DF5 45%, #8B5CF6 100%)，圆角与现有卡片一致，静态、无循环动画
   - hover：translateY(-2px) + 轻微投影，过渡 200~300ms（若现有卡片有统一 hover 规则，沿用）
3. 响应式：桌面端通栏卡与上方三张步骤卡总宽对齐；移动端所有卡片纵向堆叠，CTA 按钮不折行、不被挤压。

【验收】
- 首页其余部分零变化；两处改动与首页 hero、星尘AI 对话页 hero 的蓝紫渐变视觉同源。
- 文案无 emoji；所有跳转可用。
```

## 五、风险与回退

| 风险 | 说明 | 回退 |
|---|---|---|
| 渐变通栏卡视觉过重 | 若实际效果压过三张步骤卡，可把渐变卡降为先白卡 + 左侧渐变竖条（4px）的次级高亮 | 仅改该卡样式，不动文案与位置 |
| 首页文案多处硬编码 | 若"AI 助手"文案散落在多语言/配置文件中，需同步改全 | 全局搜索"AI 助手""智能分析与问答"确认无残留 |
