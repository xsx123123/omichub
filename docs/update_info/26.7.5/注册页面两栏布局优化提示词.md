# 注册页面表单两栏布局优化提示词

## 🎯 目标
将注册页面从当前的**单栏垂直布局**改为**两栏网格布局**，缩短卡片整体高度，同时保持现有的紫色星空主题、毛玻璃卡片、猫坐地球 Logo 等视觉风格不变。

---

## 📸 当前问题

当前注册表单为单栏垂直排列：
```
用户名
[________________]
邮箱
[________________]
密码
[________________]
确认密码
[________________]
[注册]    [返回登录]
```

4 个输入框垂直堆叠，导致卡片过长，视觉上不够紧凑精致。

---

## ✅ 优化方案

### 桌面端（≥768px）：两栏网格布局

```
┌─────────────────────────────────────┐
│           🐱🌍 注册账户              │
│        加入 OmicHub 多组学分析平台    │
├─────────────────────────────────────┤
│  用户名 *      │  邮箱 *             │
│  [__________]  │  [__________]       │
├─────────────────────────────────────┤
│  密码 *                              │
│  [______________________________]    │
├─────────────────────────────────────┤
│  确认密码 *                          │
│  [______________________________]    │
├─────────────────────────────────────┤
│  [        注册账户        ]          │
│         已有账号？返回登录            │
└─────────────────────────────────────┘
```

**布局说明**：
- **第一行**：用户名 + 邮箱（各占 50%）
- **第二行**：密码（占 100%，因为 placeholder 提示文字较长，半栏会拥挤）
- **第三行**：确认密码（占 100%）
- **第四行**：注册按钮（全宽，更醒目）+ 返回登录链接（按钮下方居中）

### 备选方案（如果密码提示可精简）

如果密码 placeholder 可以缩短为「请输入密码」，则：

```
┌─────────────────────────────────────┐
│  用户名 *      │  邮箱 *             │
│  [__________]  │  [__________]       │
├────────────────┼────────────────────┤
│  密码 *        │  确认密码 *         │
│  [__________]  │  [__________]       │
├─────────────────────────────────────┤
│  [        注册账户        ]          │
│         已有账号？返回登录            │
└─────────────────────────────────────┘
```

**推荐优先使用方案一**（密码全宽），因为当前密码提示文字较长，半栏会导致输入框拥挤或文字截断。

## 🏗️ 具体实现要求

### 1. 网格布局（CSS Grid）

```css
.register-form {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 20px 16px;  /* 行间距 20px，列间距 16px */
}

/* 占满两栏的字段 */
.register-form .form-item-full {
  grid-column: 1 / -1;
}

/* 按钮行 */
.register-form .form-actions {
  grid-column: 1 / -1;
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 12px;
  margin-top: 8px;
}
```

### 2. 表单结构（React / Arco Design）

```jsx
<Form className="register-form" layout="vertical">
  {/* 第一行：用户名 + 邮箱 */}
  <Form.Item 
    label="用户名" 
    required 
    className="form-item-half"
    rules={[{ required: true, message: '请输入用户名' }]}
  >
    <Input 
      prefix={<IconUser />} 
      placeholder="字母/数字/下划线，3-50字符" 
    />
  </Form.Item>

  <Form.Item 
    label="邮箱" 
    required 
    className="form-item-half"
    rules={[{ required: true, type: 'email', message: '请输入有效邮箱' }]}
  >
    <Input 
      prefix={<IconEmail />} 
      placeholder="请输入邮箱地址" 
    />
  </Form.Item>

  {/* 第二行：密码（全宽） */}
  <Form.Item 
    label="密码" 
    required 
    className="form-item-full"
    rules={[{ required: true, message: '请输入密码' }]}
  >
    <Input.Password 
      prefix={<IconLock />} 
      placeholder="至少8位，包含字母和数字" 
    />
  </Form.Item>

  {/* 第三行：确认密码（全宽） */}
  <Form.Item 
    label="确认密码" 
    required 
    className="form-item-full"
    rules={[
      { required: true, message: '请再次输入密码' },
      { validator: (v) => v === password || '两次输入的密码不一致' }
    ]}
  >
    <Input.Password 
      prefix={<IconLock />} 
      placeholder="请再次输入密码" 
    />
  </Form.Item>

  {/* 第四行：按钮 */}
  <div className="form-actions">
    <Button type="primary" htmlType="submit" className="btn-register-full">
      注册账户
    </Button>
    <span className="back-to-login">
      已有账号？<a href="/login">返回登录</a>
    </span>
  </div>
</Form>
```

## 🎨 视觉保持清单

修改布局时，以下元素**必须保持不变**：

- [ ] 紫色星空背景 + 粒子动画
- [ ] 猫坐地球 Logo（位置在标题上方）
- [ ] 顶部引言（"Somewhere..."）
- [ ] 底部引言（"We are made of star-stuff"）
- [ ] 卡片毛玻璃效果（`backdrop-filter: blur`）
- [ ] 输入框暗黑主题样式（半透明底 + 白字 + 紫边聚焦）
- [ ] 标签和 placeholder 颜色
- [ ] 按钮紫色渐变 + 悬浮发光

---

## ⚠️ 注意事项

1. **Arco Form 的 layout="vertical"**：两栏布局下每个 Form.Item 仍需保持 label 在输入框上方，不要改成水平 label
2. **间距一致性**：两列之间的间距（`gap: 16px`）要与上下行间距协调，不要太挤
3. **错误提示位置**：表单验证错误提示不应破坏两栏布局，错误信息应显示在对应输入框下方
4. **密码提示文字**：如果 placeholder 过长导致半栏拥挤，优先采用「方案一」（密码全宽）
5. **登录页不要改**：只修改注册页，登录页保持现有单栏布局不变
6. **过渡动画**：布局切换时如果有条件，可以给卡片加一个轻微的 `transition: max-width 0.3s ease`
