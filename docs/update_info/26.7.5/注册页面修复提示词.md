# 注册页面视觉修复与主题统一提示词

## 🎯 目标
将注册页面修复为与登录页完全一致的视觉风格，支持暗黑/亮色双主题，复用登录页的星空粒子动画背景。

---

## 📸 当前问题（见截图）

| 问题 | 描述 |
|------|------|
| **表单内容几乎不可见** | 输入框、标签文字对比度极低，白色卡片上的表单元素像是"隐身"了 |
| **没有暗黑模式** | 背景是默认亮蓝色，与登录页紫色星空主题割裂 |
| **缺少动画背景** | 登录页有星空粒子流动，注册页完全没有 |
| **整体风格不统一** | 像是两个不同的产品 |

---

## ✅ 修复要求

### 1. 主题系统（最高优先级）

注册页必须**完全复用**登录页的主题切换逻辑：

- **暗黑模式**：深紫渐变背景 (`#1a0b2e` → `#2d1b4e`) + 星空粒子动画
- **亮色模式**：淡紫渐变背景 (`#e0d4f7` → `#c4b5fd`) + 柔和粒子
- **切换方式**：与登录页共用同一个主题状态（localStorage / Context / Redux 中的 `theme`）
- **默认主题**：跟随系统偏好，或保持与登录页一致

```css
/* 暗黑模式背景 - 与登录页完全一致 */
.register-page.dark {
  background: linear-gradient(135deg, #1a0b2e 0%, #2d1b4e 50%, #1e1b4b 100%);
}

/* 亮色模式背景 */
.register-page.light {
  background: linear-gradient(135deg, #e0d4f7 0%, #c4b5fd 50%, #ddd6fe 100%);
}
```

### 2. 星空粒子动画（复用登录页）

**直接复用**登录页已有的粒子动画组件，不要重新写：

```jsx
// 假设登录页的粒子组件叫 StarField
import StarField from '../Login/StarField';  // 或对应路径

// 在注册页直接使用
<StarField theme={currentTheme} />
```

要求：
- 粒子颜色随主题变化：暗黑模式用白色/淡紫，亮色模式用深紫/灰色
- 粒子密度、速度、鼠标交互效果与登录页完全一致
- 粒子在卡片**背后**渲染，`z-index` 低于卡片

```jsx
// RegisterPage.jsx

import './RegisterPage.css';

const RegisterPage = () => {
  const { theme } = useContext(ThemeContext); // 'dark' | 'light'

  return (
    <div className={`register-page ${theme}`}>
      {/* 星空背景 - 与登录页完全一致 */}
      <StarField theme={theme} />

      {/* 顶部引言 */}
      <div className={`top-quote ${theme}`}>

      </div>

      {/* 注册卡片 */}
      <div className={`register-card ${theme}`}>
        {/* Logo（如有） */}
        <LogoAnimation size="small" />

        <h1 className={`register-title ${theme}`}>注册账户</h1>
        <p className={`register-subtitle ${theme}`}>加入 OmicHub 多组学分析平台</p>

        <RegisterForm theme={theme} />
      </div>

      {/* 底部引言 */}
      <div className={`bottom-quote ${theme}`}>
        <p className="quote-en">"We are made of star-stuff"</p>
        <p className="quote-cn">我们只是借用了宇宙中的这些原子，短暂地体验了一次这个世界。</p>
      </div>
    </div>
  );
};
```

## ⚠️ 特别注意

1. **不要重新发明轮子**：粒子动画、主题切换、Logo 组件全部复用登录页已有代码
2. **Arco Design 样式覆盖**：如果使用 Arco 的 Form/Input 组件，可能需要增加 CSS 权重（`!important` 或更具体的选择器）来覆盖默认样式
3. **主题同步**：注册页和登录页的主题必须实时同步，切换一个页面另一个也要跟着变
4. **表单可见性**：这是当前最严重的问题，务必确保所有输入框在两种主题下都清晰可见
5. **测试清单**：
   - [ ] 暗黑模式下所有表单元素可见
   - [ ] 亮色模式下所有表单元素可见
   - [ ] 粒子动画正常播放
   - [ ] 主题切换流畅
   - [ ] 移动端显示正常
   - [ ] 与登录页风格完全一致
