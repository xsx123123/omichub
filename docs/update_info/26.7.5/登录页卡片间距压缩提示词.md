# 登录页卡片垂直间距压缩提示词

## 🎯 目标
压缩登录卡片（白色/毛玻璃框）的垂直空白，让整体更紧凑精致，减少"上方太空"的视觉感受。

---

## 📸 当前问题

看截图，登录卡片内部存在过多垂直空白：

```
┌─────────────────────────┐
│                         │  ← 顶部留白过大（约 40-50px）
│         🐱🌍            │  ← Logo 区域
│                         │  ← Logo 到标题间距过大
│       OmicHub           │
│    欢迎登录多组学分析平台 │
│                         │
│    用户名               │
│   [________________]    │
│                         │  ← 字段之间间距也偏大
│    密码                 │
│   [________________]    │
│                         │
│  [登录]  [还没有账号...] │
│                         │  ← 底部留白也偏大
└─────────────────────────┘
```

---

## ✅ 调整方案

### 1. 卡片整体内边距压缩

```css
.login-card {
  /* 当前可能是 padding: 40px 36px; */
  padding: 28px 32px 32px 32px;  /* 上 28px，左右 32px，下 32px */

  /* 保持现有样式 */
  background: rgba(255, 255, 255, 0.08);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.12);
  border-radius: 16px;
}
```

### 2. Logo 区域间距压缩

```css
.login-logo-wrapper {
  /* 当前可能是 margin-bottom: 24px; */
  margin-bottom: 16px;  /* Logo 到标题的距离缩短 */
  margin-top: 0;        /* 紧贴卡片顶部 */
}

/* 如果 Logo 外层还有额外 padding，一并移除 */
.login-logo-container {
  padding-top: 0;
}
```

### 3. 标题区域间距压缩

```css
.login-title {
  font-size: 28px;
  font-weight: 700;
  color: #8b9cf6;  /* 保持现有渐变紫蓝色 */
  margin-bottom: 6px;  /* 当前可能是 12px，缩短 */
  margin-top: 0;
}

.login-subtitle {
  font-size: 14px;
  color: rgba(255, 255, 255, 0.55);
  margin-bottom: 24px;  /* 当前可能是 32-40px，缩短到 24px */
}
```

### 4. 表单字段间距压缩

```css
/* Arco Form 的 item 间距 */
.login-form .arco-form-item {
  margin-bottom: 16px;  /* 当前可能是 20-24px，缩短到 16px */
}

/* 最后一个表单 item 到按钮的距离 */
.login-form .arco-form-item:last-of-type {
  margin-bottom: 20px;  /* 当前可能是 28-32px */
}
```

### 5. 按钮区域间距

```css
.login-actions {
  display: flex;
  gap: 12px;           /* 保持现有按钮间距 */
  margin-top: 0;       /* 移除额外上边距 */
  margin-bottom: 0;
}
```

## 📐 调整前后对比

| 区域 | 当前（估算） | 调整后 |
|------|-------------|--------|
| 卡片顶部 padding | ~40px | **28px** |
| Logo → 标题 | ~24px | **16px** |
| 标题 → 副标题 | ~12px | **6px** |
| 副标题 → 第一个输入框 | ~36px | **24px** |
| 输入框之间 | ~20-24px | **16px** |
| 最后一个输入框 → 按钮 | ~28px | **20px** |
| 卡片底部 padding | ~40px | **32px** |

## 🏗️ 完整 CSS 参考

```css
/* 登录卡片 */
.login-card {
  width: 100%;
  max-width: 400px;
  padding: 28px 32px 32px;
  background: rgba(255, 255, 255, 0.08);
  backdrop-filter: blur(20px);
  -webkit-backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.12);
  border-radius: 16px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);
}

/* Logo 区域 */
.login-logo-area {
  display: flex;
  justify-content: center;
  margin-bottom: 16px;
}

.login-logo-area svg,
.login-logo-area img {
  width: 80px;
  height: 80px;
}

/* 标题 */
.login-title {
  font-size: 28px;
  font-weight: 700;
  text-align: center;
  color: #8b9cf6;
  margin: 0 0 6px 0;
}

/* 副标题 */
.login-subtitle {
  font-size: 14px;
  text-align: center;
  color: rgba(255, 255, 255, 0.55);
  margin: 0 0 24px 0;
}

/* 表单 */
.login-form .arco-form-item {
  margin-bottom: 16px;
}

.login-form .arco-form-item:last-child {
  margin-bottom: 20px;
}

/* 按钮行 */
.login-actions {
  display: flex;
  gap: 12px;
}

.login-actions .arco-btn {
  flex: 1;
  height: 44px;
  border-radius: 10px;
}
```

---

## ⚠️ 注意事项

1. **不要压缩过度**：上下 padding 不要小于 24px，否则卡片内容会贴边，失去"呼吸感"
2. **保持水平 padding**：左右 `32px` 不要动，保持输入框两侧留白舒适
3. **Logo 大小**：如果压缩后 Logo 显得太大，可以微调 Logo 尺寸从 `80px` 到 `72px`
4. **移动端适配**：移动端（<480px）padding 可以进一步压缩到 `24px 20px 28px`
5. **注册页同步**：如果注册页也做了类似的紧凑调整，保持两页风格一致
6. **测试**：调整后检查输入框聚焦时的紫色光环不要被卡片边缘截断
