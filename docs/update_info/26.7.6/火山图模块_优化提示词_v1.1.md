# 🎯 火山图绘制模块优化提示词

## 一、优化概述

基于当前火山图绘制模块的实现，进行以下 3 项优化：
1. **压缩页面留白** — 减小标题区、面包屑、图表容器之间的垂直间距，让图表区域更紧凑
2. **新增坐标轴与标题配置** — 支持手动设置 X/Y 轴范围、轴标题、Plot 标题
3. **PNG 导出 DPI 设置为 1000** — Plotly 导出高清 PNG

### 2.3 PNG 导出 DPI 设置为 1000（问题 3）

**技术方案**：

Plotly 的 `toImage` 方法通过 `scale` 参数控制导出分辨率。默认导出尺寸为图表当前像素尺寸（假设 96 DPI），要获得 1000 DPI 的 PNG：

```typescript
// 假设图表在屏幕上的显示尺寸为 800 x 600 像素
// 要获得 1000 DPI，需要导出像素 = 显示尺寸 × (1000 / 96)
// scale ≈ 10.42

const EXPORT_DPI = 1000;
const SCREEN_DPI = 96;
const SCALE_FACTOR = EXPORT_DPI / SCREEN_DPI; // ≈ 10.42

async function exportPNG() {
  const plotEl = plotRef.current;
  if (!plotEl) return;

  // 获取当前图表尺寸
  const rect = plotEl.getBoundingClientRect();
  const width = Math.round(rect.width);
  const height = Math.round(rect.height);

  // 计算导出尺寸：目标 1000 DPI
  // 方式1：使用 scale 参数（推荐，保持比例）
  const imageData = await plotEl.toImage({
    format: 'png',
    width: width,
    height: height,
    scale: SCALE_FACTOR,      // 关键：放大 10.42 倍
  });

  // 方式2：直接指定高像素（备选）
  // const imageData = await plotEl.toImage({
  //   format: 'png',
  //   width: Math.round(width * SCALE_FACTOR),
  //   height: Math.round(height * SCALE_FACTOR),
  //   scale: 1,
  // });

  // 下载
  const link = document.createElement('a');
  link.href = imageData;
  link.download = `volcano_plot_${Date.now()}_1000dpi.png`;
  link.click();
}
```

**完整导出配置**：

```typescript
interface ExportOptions {
  format: 'png' | 'svg' | 'jpeg';
  dpi?: number;  // 仅 PNG/JPEG 有效
}

async function exportImage(options: ExportOptions) {
  const { format, dpi = 1000 } = options;
  const plotEl = plotRef.current;
  if (!plotEl) return;

  if (format === 'svg') {
    // SVG 为矢量，无需 DPI 设置
    const imageData = await plotEl.toImage({ format: 'svg' });
    download(imageData, `volcano_plot_${Date.now()}.svg`);
    return;
  }

  // PNG / JPEG：高 DPI 导出
  const rect = plotEl.getBoundingClientRect();
  const scale = dpi / 96;

  const imageData = await plotEl.toImage({
    format,
    width: Math.round(rect.width),
    height: Math.round(rect.height),
    scale,
  });

  download(imageData, `volcano_plot_${Date.now()}_${dpi}dpi.${format}`);
}
```

- [ ] 新增「坐标轴与标题」折叠面板，包含全部 8 个配置项
- [ ] 自动模式下，X/Y 轴范围与原有逻辑完全一致

- [ ] 点击「导出 PNG」默认输出 1000 DPI
- [ ] 导出文件尺寸 ≈ 显示尺寸 × 10.42（如 800×600 显示 → 约 8333×5000 像素）
- [ ] 导出 PNG 清晰无锯齿，文字和散点边缘锐利
- [ ] SVG 导出不受 DPI 设置影响，仍为矢量格式
- [ ] 导出文件名包含时间戳和 DPI 信息，如 `volcano_plot_20260706_143052_1000dpi.png`

### 6.2 Plotly Layout 更新（plotlyConfig.ts）

```typescript
export function generatePlotlyLayout(config: VolcanoConfig, isDark: boolean) {
  const { 
    xAxisMode, xMin, xMax, 
    yAxisMode, yMin, yMax,
    xAxisTitle, yAxisTitle, plotTitle, autoWrapTitle,
    expName, lfcCutoff, pvalCutoff, showThreshold,
    xMaxAuto, yMaxAuto  // 自动计算的值
  } = config;

  // 轴范围
  const xRange = xAxisMode === 'auto' 
    ? [-xMaxAuto, xMaxAuto] 
    : [xMin, xMax];
  const yRange = yAxisMode === 'auto' 
    ? [0, yMaxAuto] 
    : [yMin, yMax];

  // 标题
  let title = plotTitle.trim();
  if (!title) {
    title = `${expName} Volcano Plot`;
  }
  if (autoWrapTitle && title.length > 30) {
    title = title.slice(0, 30) + '\n' + title.slice(30);
  }

  return {
    title: {
      text: title,
      font: { size: 16, color: isDark ? '#fff' : '#333' },
      x: 0.5,
      xanchor: 'center',
    },
    xaxis: {
      title: xAxisTitle || `log₂ fold change (${expName})`,
      range: xRange,
      zeroline: false,
      gridcolor: isDark ? '#333' : '#eee',
      color: isDark ? '#fff' : '#333',
      showgrid: true,
      tickfont: { size: 11 },
    },
    yaxis: {
      title: yAxisTitle || '-log₁₀(padj)',
      range: yRange,
      zeroline: false,
      gridcolor: isDark ? '#333' : '#eee',
      color: isDark ? '#fff' : '#333',
      showgrid: true,
      tickfont: { size: 11 },
    },
    margin: { t: 40, r: 30, b: 60, l: 60 },  // 紧凑 margin
    shapes: showThreshold ? generateThresholdShapes(xRange, yRange, lfcCutoff, pvalCutoff) : [],
    // ... 其他配置
  };
}
```

### 6.3 高 DPI PNG 导出（ExportToolbar.tsx）

```typescript
const handleExportPNG = async (dpi: number = 1000) => {
  if (!plotRef.current) return;

  const rect = plotRef.current.getBoundingClientRect();
  const scale = dpi / 96;

  try {
    const imageData = await plotRef.current.toImage({
      format: 'png',
      width: Math.round(rect.width),
      height: Math.round(rect.height),
      scale,
    });

    const link = document.createElement('a');
    link.href = imageData;
    link.download = `volcano_plot_${formatDate(new Date())}_${dpi}dpi.png`;
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);

    Message.success(`PNG 导出成功 (${dpi} DPI)`);
  } catch (err) {
    Message.error('导出失败：' + err.message);
  }
};
```
