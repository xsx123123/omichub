# 左侧导航栏图标尺寸统一修复

> 问题：三条杠（汉堡菜单）图标与蓝色加号按钮的视觉大小不一致
> 位置：左侧导航栏顶部区域

---

## 一、问题分析

从截图观察，左侧导航栏顶部存在两个交互元素：

| 元素 | 当前状态 | 问题 |
|------|---------|------|
| ☰ 三条杠（菜单/展开按钮） | 纯图标，无背景 | 尺寸偏小，视觉轻 |
| ➕ 蓝色加号按钮 | 带背景色的方形按钮 | 尺寸偏大，视觉重 |

两者并列时产生**视觉失衡**，加号按钮过于突兀，三条杠则显得单薄。

---

## 二、修复方案

### 方案 A：统一为「图标按钮」风格（推荐）

将加号按钮降级为与三条杠同级的纯图标，或给三条杠添加同尺寸背景容器，实现视觉对称。

```css
/* 左侧导航栏顶部控制区 */
.nav-top-controls {
  display: flex;
  align-items: center;
  justify-content: space-between;  /* 或 center，根据布局需求 */
  padding: 12px 16px;
  gap: 12px;
}

/* 统一按钮基础样式 */
.nav-icon-btn {
  width: 36px;
  height: 36px;
  display: flex;
  align-items: center;
  justify-content: center;
  border-radius: 10px;          /* 统一圆角 */
  border: none;
  cursor: pointer;
  transition: all 0.2s ease;
  font-size: 18px;              /* 统一图标大小 */
}

/* 三条杠 —— 浅色背景 */
.nav-icon-btn.menu-btn {
  background: transparent;
  color: var(--color-text-2, #86909c);
}

.nav-icon-btn.menu-btn:hover {
  background: var(--color-fill-2, #f2f3f5);
  color: var(--color-text-1, #1d2129);
}

/* 加号 —— 品牌色背景 */
.nav-icon-btn.add-btn {
  background: var(--color-primary, #165DFF);
  color: #fff;
}

.nav-icon-btn.add-btn:hover {
  background: var(--color-primary-dark, #0e42d2);
  transform: scale(1.05);
}

/* 图标内部 SVG/字体统一大小 */
.nav-icon-btn svg,
.nav-icon-btn .arco-icon {
  width: 18px;
  height: 18px;
  font-size: 18px;
}
```

### React 组件调整

```tsx
// 左侧导航栏顶部
<div className="nav-top-controls">
  <button className="nav-icon-btn menu-btn" title="展开菜单">
    <IconMenu />  {/* Arco Design IconMenu */}
  </button>

  <button className="nav-icon-btn add-btn" title="新建对话">
    <IconPlus />  {/* Arco Design IconPlus */}
  </button>
</div>
```

### 方案 B：统一为「方形按钮」风格

给三条杠也加上与加号同尺寸的背景容器，形成对称的按钮组。

```css
.nav-top-controls {
  display: flex;
  align-items: center;
  padding: 12px 16px;
  gap: 10px;
}

/* 统一方形按钮 */
.nav-square-btn {
  width: 40px;
  height: 40px;
  display: flex;
  align-items: center;
  justify-content: center;
  border-radius: 12px;
  border: none;
  cursor: pointer;
  transition: all 0.2s ease;
  font-size: 20px;
}

/* 菜单按钮 —— 浅色 */
.nav-square-btn.menu-btn {
  background: var(--color-fill-2, #f2f3f5);
  color: var(--color-text-2, #86909c);
}

.nav-square-btn.menu-btn:hover {
  background: var(--color-fill-3, #e5e6eb);
  color: var(--color-text-1, #1d2129);
}

/* 加号按钮 —— 品牌色 */
.nav-square-btn.add-btn {
  background: var(--color-primary, #165DFF);
  color: #fff;
}

.nav-square-btn.add-btn:hover {
  background: var(--color-primary-dark, #0e42d2);
}

/* 图标统一 */
.nav-square-btn svg,
.nav-square-btn .arco-icon {
  width: 20px;
  height: 20px;
}
```

---

### 方案 C：微调现有样式（最小改动）

如果不想重构结构，直接微调现有元素的尺寸使其对齐。

```css
/* 仅调整三条杠图标大小，使其与加号按钮内图标同尺寸 */
.nav-menu-icon {
  width: 20px;        /* 原来可能是 16px */
  height: 20px;
  font-size: 20px;
}

/* 或缩小加号按钮 */
.nav-add-btn {
  width: 32px;        /* 原来可能是 40px */
  height: 32px;
  border-radius: 8px; /* 相应缩小圆角 */
}

.nav-add-btn svg {
  width: 16px;        /* 图标也同步缩小 */
  height: 16px;
}
```

## 四、推荐参数速查

| 方案 | 按钮尺寸 | 图标尺寸 | 圆角 | 适用场景 |
|------|---------|---------|------|---------|
| A（图标按钮） | 36×36px | 18px | 10px | 简洁轻量，推荐 |
| B（方形按钮） | 40×40px | 20px | 12px | 操作感强，可点击区域大 |
| C（最小改动） | 按需微调 | 16-20px | 原样 | 快速修复，不动结构 |

## 五、Arco Design 组件版本

如果使用 Arco Button 组件，可直接通过 `size` 和 `shape` 属性统一：

```tsx
import { Button, Space } from '@arco-design/web-react';
import { IconMenu, IconPlus } from '@arco-design/web-react/icon';

// 方案 A：icon-only 风格
<Space size={12} className="nav-top-controls">
  <Button
    type="text"
    size="small"
    icon={<IconMenu style={{ fontSize: 18 }} />}
    style={{ width: 36, height: 36, borderRadius: 10 }}
  />
  <Button
    type="primary"
    size="small"
    icon={<IconPlus style={{ fontSize: 18 }} />}
    style={{ width: 36, height: 36, borderRadius: 10, padding: 0 }}
  />
</Space>

// 方案 B：secondary 风格
<Space size={10} className="nav-top-controls">
  <Button
    type="secondary"
    size="small"
    icon={<IconMenu style={{ fontSize: 20 }} />}
    style={{ width: 40, height: 40, borderRadius: 12, padding: 0 }}
  />
  <Button
    type="primary"
    size="small"
    icon={<IconPlus style={{ fontSize: 20 }} />}
    style={{ width: 40, height: 40, borderRadius: 12, padding: 0 }}
  />
</Space>
```

---

> 💡 **建议**：推荐 **方案 A**，将两者统一为 36×36px 的 icon-only 按钮，加号用品牌蓝底，三条杠用透明/悬停灰底，视觉最轻盈，与 Arco Design 设计语言也最一致。
