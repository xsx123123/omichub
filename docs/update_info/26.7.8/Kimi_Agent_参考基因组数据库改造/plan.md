# OmicHub 数据库模块重新设计 - 执行计划

## 目标
将现有的"参考基因组"模块升级为全面的"数据库"模块，支持 FA/GFF/GO/KEGG 多类型数据库管理、跨版本基因映射，前端风格与首页星空主题统一。

## Stage 1 — 研究阶段
- 研究 GenBank (NCBI) 的基因数据库设计模式
- 研究 Ensembl 的基因数据库架构和界面设计
- 研究基因组版本映射（Liftoff / CrossMap）的最佳实践
- 研究 GFF/GO/KEGG 数据的标准存储和查询方式
- 输出：研究报告，包含设计参考点和架构建议

## Stage 2 — 架构设计阶段
- 设计数据库模块的整体架构（数据模型、API、前端组件）
- 设计 YAML 配置规范（数据库注册方式）
- 设计基因详情页面布局（参考 GenBank/Ensembl 基因页面）
- 设计跨版本基因映射功能
- 输出：完整的 PRD 设计文档

## Stage 3 — 前端实现阶段
- 基于设计文档实现 React 前端代码
- 数据库列表页（星空主题风格）
- 基因搜索与浏览页
- 基因详情页（参考 Ensembl 基因视图）
- 跨版本映射对比视图
- 输出：完整的前端代码
