# 会话日志排查页面 —— 可观测性评估与优化计划

> 评估对象：OmicHub 系统管理 · 会话日志排查页面（2026-08-01 截图版本）
> 评估基准：Langfuse / LangSmith / Datadog LLM Observability 等业界主流 AI 可观测性实践
> 状态：**Part 1 评估结论已确认，提示词待用户确认优先级后追加**

---

## 1. 评估结论（Verdict）

页面方向正确：按会话聚合日志、列表 + 抽屉详情的信息架构与主流工具一致。
但目前只覆盖了可观测性四大支柱中的「日志」一根，且日志内容是**数据库层 SQL 日志**
（SQLAlchemy 的 chat_messages / chat_sessions 增删查改），**不是 AI 语义层日志**
（LLM 请求响应、提示词、工具调用、token 用量）。

**当前定位：会话日志查看器。目标定位：AI 可观测性排查工具。** 差距集中在三块：
Trace 视图、Metrics 仪表盘、运行报告。

### 四大支柱覆盖度

| 支柱 | 现状评级 | 已实现 | 缺口 |
|---|---|---|---|
| 日志 Logs | ⚠️ 部分 | 会话聚合、级别徽章、时间戳、轮转归档开关、trace id 文本 | AI 语义层日志缺失；用户消息明文暴露在 SQL 参数中；无级别/类型过滤、无会话内搜索 |
| Trace | ❌ 未实现 | trace id 已随日志输出（好的基础） | 无 trace 详情页；无 span 树/瀑布图；无分步耗时与 token |
| Metrics | ❌ 未实现 | 消息数、最近活跃 | token 用量、成本、延迟分位数、错误率、按模型/用户/模式聚合趋势 |
| 运行报告 | ❌ 未实现 | — | 单会话运行小结；可导出的周期报告（日报/周报） |

## 2. 问题清单与优化方案

### 2.1 商业化维度（按优先级）

| # | 优先级 | 问题 → 方案 |
|---|---|---|
| C1 | P0 合规红线 | SQL 参数明文携带用户聊天内容 → 敏感参数默认脱敏折叠（显示长度+哈希），展开需二次确认并写入审计日志；记录"谁在何时查看了哪个会话日志" |
| C2 | P0 | 无日志过滤手段 → 级别筛选（DEBUG/INFO/WARN/ERROR）+ 类型筛选（SQL / LLM / 工具调用 / 系统）+ 会话内全文搜索 |
| C3 | P1 核心卖点 | trace id 是纯文本 → 可点击 chip，打开 trace 详情页：span 树/瀑布图，每节点含输入输出、耗时、token 数 |
| C4 | P1 | 无告警 → 错误率 >5% 持续 5 分钟、p95 延迟 >10s、日成本超 7 日均值 150% 触发告警，接入平台通知公告渠道 |
| C5 | P2 | 无导出 → 会话日志导出 JSON/CSV；一键生成单会话运行报告（总 token、成本、耗时、工具调用统计、错误摘要） |
| C6 | P2 | 留存策略 → 在"轮转归档"基础上做可配置留存周期（热数据 7 天 / 冷数据 90 天） |

### 2.2 前端维度

**列表页**
- F1 UUID 列：改等宽字体（`font-family: ui-monospace, monospace`）、字号 -1、点击复制、悬停 tooltip 显示完整值
- F2 用户列：显示用户名/昵称替代截断 UUID，悬停给完整 ID
- F3 增加：时间范围筛选、按消息数/最近活跃排序、分页器（当前未见分页控件）
- F4 模式下拉带计数（对话 128 / AI 工作台 45）
- F5 搜索框回车触发查询，增加「重置」按钮

**日志抽屉**
- F6 SQL 语句语法高亮；`generated in 0.00023s` 提取为性能徽章；参数区默认折叠
- F7 时间戳统一 `MM-DD HH:mm:ss.SSS`（当前只有时分秒，跨天排查混淆）
- F8 ERROR 级日志整行红色高亮，不只靠徽章
- F9 增加：会话内搜索框、级别过滤 chips、tail 模式（自动滚底）、单条复制按钮
- F10 抽屉 ESC 关闭、宽度可拖拽

## 3. 分阶段实施建议

| 阶段 | 内容 | 独立可验 |
|---|---|---|
| Phase 1（合规与可用性，1 周内） | C1 脱敏+审计、C2 过滤搜索、F6–F10 抽屉体验 | 管理员能只看 ERROR、搜关键词，日志不再明文暴露聊天内容 |
| Phase 2（Trace 视图） | C3 trace 详情页 + F1–F5 列表优化 | 从列表点 trace id 能看到一次对话的完整调用链瀑布图 |
| Phase 3（Metrics 与告警） | Metrics 仪表盘（或与现有"用量统计"页联动）、C4 告警 | 能看到按日 token/成本/错误率趋势，超阈值收通知 |
| Phase 4（报告与留存） | C5 导出与运行报告、C6 留存配置 | 一键导出会话运行报告 PDF/JSON |

## 4. 验收 Checklist

- [ ] 日志中用户消息内容默认不可见（脱敏），展开动作有审计记录
- [ ] 会话内可按级别/类型/关键词过滤日志
- [ ] trace id 可点击，trace 详情含每步耗时与 token
- [ ] 列表显示用户名，支持时间筛选、排序、分页
- [ ] Metrics 页可见 token/成本/错误率/延迟趋势
- [ ] 超阈值告警可送达通知渠道
- [ ] 单会话运行报告可导出
