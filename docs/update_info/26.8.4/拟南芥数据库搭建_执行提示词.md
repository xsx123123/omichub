### 必须实现的交付物

**A. 后端模块**（结构照蓝图 §二，禁止改 `integrations/`、`deploy/`、不加新依赖、不做 git 写操作）：

- `src/omichub/reference_genomes/`：`__init__.py`、`api.py`、`service.py`、`schema.py`、`config.py`、`indexer.py`、`sequence.py`；
- `config.py`：YAML 加载器（**mtime 热重载**、文件缺失/解析失败回退空配置绝不抛异常、单例，照蓝图 §十）；
- `src/omichub/core/config.py` Settings 加 `reference_genomes_yaml`（默认 `/app/refdata/reference_genomes.yaml`，支持环境变量覆盖，本地跑用仓库内 `refdata/reference_genomes.yaml`）；
- `src/omichub/api/v1/router.py` 注册 `prefix="/reference-genomes"`；全部端点 `Depends(get_current_user)`。

**B. 注册表**：`refdata/reference_genomes.yaml` 登记 arabidopsis/tair10（species→versions 两级结构照设计文档 §4.1），路径指向上面的真实文件；`go-basic.obo` 留在 TAIR10 目录直接用即可（暂不做 _shared 迁移）。

**C. SQLite 索引**（表结构照设计文档 §4.2：genes FTS5、transcripts、go_terms、go_annotations、kegg_kos、kegg_pathways、kegg_annotations、id_mapping、meta）：

- `indexer.py` 支持 `python -m omichub.reference_genomes.indexer build --version tair10 [--only gff3|go|kegg|fasta]`；先写临时文件再原子替换；meta 表写 build_status/built_at/gene_count；
- 解析器：`genomic_fasta`（解压+纯 Python 生成 .fai）、`gff3`（Parent 多值、exon 回溯到 gene 计数）、`tair_functional`（functional_descriptions，取 Short_description 落入 genes.annotation，Curator_summary 优先）、`fasta_kv`（cds/pep 登记 transcript_id）、`gaf`、`obo`、`kegg_ko`、`kegg_pathway`、`kegg_pathway_name`、`kegg_gene`；
- **全部纯 Python、流式读 gzip，不引入任何新依赖**。

**D. 序列读取**：`sequence.py` 纯 Python faidx 读取器（解析 .fai 的 offset/linebases/linewidth，seek 取区间，负链反向互补）；CDS/蛋白按转录本 ID 从对应 FASTA 取（构建时记录偏移或建 seq_kv，二选一，需说明理由）。

**E. API 端点**（设计文档 §5，响应字段 alias 输出 camelCase）：

- `GET /species`、`GET /versions/{id}`（含文件审计状态 ready/missing + 染色体统计）
- `GET /versions/{id}/genes?field=gene_id|gene_name|annotation|go|kegg&q=&chromosome=&page=&page_size=`（**gene_id 用 LIKE，name/annotation 用 FTS5 MATCH 并回退 LIKE**）
- `GET /versions/{id}/genes/{gene_id}`（聚合：gene + transcripts + go + kegg + sequenceAvailable，GO/KEGG 各截断 100 条）
- `GET /versions/{id}/genes/{gene_id}/sequence?type=genomic|cds|protein&format=fasta|json`、`GET /versions/{id}/sequence?chrom=&start=&end=&strand=`（区间 ≤1Mb）
- `GET /versions/{id}/go?q=`、`GET /versions/{id}/kegg/pathways?q=`、`GET /versions/{id}/go/{go_id}/genes`（反查）
- `GET /versions/{id}/search?q=`（基因/GO/KEGG 三类聚合）与 `GET /search?q=`（全局）
- `POST /versions/{id}/genes/batch`（≤500 ID → annotation + GO/KEGG 计数）
- `POST /reload`（管理员，强制重载 YAML）

**F. 前端接线**（后端全通之后做）：新建 `frontend/src/api/referenceGenomes.ts` + `frontend/src/types/referenceGenomes.ts`（从 `mock/referenceGenomes.ts` 提取类型）；`ReferenceGenomesView.vue` 列表与搜索框、`ReferenceGenomeDetailView.vue` 概览/基因 Tab/基因抽屉五 Tab（Summary/Transcripts/GO/KEGG/Sequence）改调 API；其余物种卡片可以正常显示 missing 状态。**禁止改 UI 布局，只换数据源。**

### 验证锚点（全部通过才算完成）

1. `python -m omichub.reference_genomes.indexer build --version tair10` 成功，meta 表 gene_count=28775（±容差 0），transcripts=35386。
2. `GET /versions/tair10/genes?field=gene_id&q=AT1G01010` 返回该基因：**Chr1, 3631-5899, + 链, NAC domain containing protein 1**，毫秒级。
3. `GET /versions/tair10/genes/AT1G01010` 聚合里：GO 非空；KEGG 含 KO `K28554`。
4. `GET /versions/tair10/genes/AT1G51370/sequence?type=cds` 返回以 `ATGGTGGGTGGCAAGAAG` 开头的序列（transcript AT1G51370.2）；`type=protein` 以 `MVGGKKKTKICDKVSHEE` 开头；`GET /versions/tair10/sequence?chrom=Chr1&start=3631&end=3730` 与 `samtools faidx`（若环境有）或人工抽查一致；负链基因返回反向互补。
5. `field=go&q=GO:0003700`（或 kinase）能反查基因列表；`field=kegg&q=glycolysis` 能反查。
6. `GET /search?q=NAC` 同时命中 genes 与 goTerms。
7. 改 yaml（如加个注释字段）**不重启进程**，下一个请求即生效（验证 mtime 热重载）；yaml 改名指向不存在文件时不报错、species 列表降级为空。
8. 单测：每个解析器用真实文件的 head 切片做 fixture；faidx 读取器边界（跨行、负链、区间越界）；API 层参数校验。`pytest tests/unit -k reference_genomes` 全绿，且不破坏既有测试。
9. 前端 `npm run build`（或 package.json 里对应脚本）通过；页面打开可见拟南芥卡片真实数据，基因抽屉五 Tab 均为真实数据。
