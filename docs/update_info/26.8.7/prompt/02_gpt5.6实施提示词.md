## 1. 背景(两分钟版)

- 超频轮(Overdrive)是 multi-agent 主链路:`chat_service.py:_run_overdrive_turn` → Manager LLM 规划 → fan-out 执行。
- 认知层七个位置写死了任务知识(设计文档 §3 的 S1–S7):`_is_overdrive_planning_request`、`_analysis_intake_questions`、`_extract_overdrive_intake_slots`、`_filter_overdrive_questions`、`_overdrive_capability_profile`、`_default_overdrive_assignments`、`_minimize_overdrive_assignments`,全部在 `src/omichub/application/services/chat_service.py`(:345-813)。
- 调度 prompt 两处任务条款:`OVERDRIVE_MANAGER_PROMPT` 规则 10(:276,系统发育树)、`ROUTER_SYSTEM_PROMPT` 规则 9(:221,RNA-seq 判歧)。
- 目标终态:这些知识全部搬到 `data/ai/domains/*.yaml`(Domain Pack)和 agent YAML 的 `features.default_role/capability_scope`,代码变成对 `DomainRegistry` 的通用求值。新增任务类型 = 加一个 YAML,调度代码/prompt 零改动。
