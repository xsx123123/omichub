### 2.1 执行方式

宿主机直接跑仓内 alembic（`alembic/env.py` 使用 async engine，读取
`core/config.py Settings.database_url`）。因 `.env` 中 host 为容器网络名 `db`，
宿主机执行时用环境变量覆盖（密码取自 pgbouncer 容器环境变量，未落盘、未外显）：

```bash
PW=$(docker exec cygnusx-pgbouncer printenv DB_PASSWORD)
export DATABASE_URL="postgresql+asyncpg://omichub:${PW}@127.0.0.1:5432/omichub"
uv run alembic <args>
```
